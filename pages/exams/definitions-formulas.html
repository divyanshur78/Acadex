REFERENCE 01

Function Basics and Notation

Important definitions

Function
A function is a relation that assigns exactly one output to every element of its domain.
Domain
The set of all permitted input values of a function.
Codomain
The set declared as the possible output set of a function.
Range
The set of output values actually obtained when all permitted inputs are used. The range is a subset of the codomain.
Function notation
In f : A → B, A is the domain, B is the codomain, and f(x) represents the output corresponding to input x.

Important formulas and notation

Function mapping: f : A → B

Output: y = f(x)

Range: Range(f) = {f(x) : x ∈ A}

Range relationship: Range(f) ⊆ B

Example: If f(x) = 2x + 3, then f(2) = 7.

REFERENCE 02

Types and Classification of Functions

Important definitions

One-one (Injective)
A function is one-one if different inputs always produce different outputs. If f(a) = f(b), then a = b.
Many-one
A function is many-one when two or more distinct inputs can have the same output.
Onto (Surjective)
A function is onto when every element of its codomain is mapped to by at least one element of its domain.
Into
A function is into when at least one element of the codomain is not included in its range.
Bijective
A function is bijective when it is both one-one and onto.
Identity function
A function that maps every element to itself.
Constant function
A function that gives the same output for every input in its domain.

Important formulas and tests

One-one test: f(a) = f(b) ⇒ a = b

Onto condition: Range(f) = Codomain

Bijective condition: One-one + Onto

Identity function: f(x) = x

Constant function: f(x) = c, where c is constant

Graphical one-one test: Every horizontal line intersects the graph at most once.

REFERENCE 03

Domain and Range Rules

Important definitions

Restricted domain
A domain in which certain input values are excluded because the function is not defined for them.
Denominator restriction
A rational expression is undefined wherever its denominator equals zero.
Radicand
The expression inside a radical sign. For a real-valued square root, the radicand must be non-negative.
Logarithm argument
The expression inside a logarithm. For real logarithms, its value must be strictly positive.

Important domain rules

Polynomial: Domain = R

Rational function: Denominator ≠ 0

Even root: Expression inside the root ≥ 0

Odd root: Domain = R for ordinary real-valued root expressions

Logarithmic function: Argument > 0

Exponential function: Domain = R

Example: For f(x) = 1/(x - 2), x ≠ 2.

Example: For g(x) = √(x - 3), x ≥ 3.

Example: For h(x) = log(x + 4), x > -4.

REFERENCE 04

Operations on Functions

Important definitions

Sum of functions
The function obtained by adding the outputs of two functions.
Difference of functions
The function obtained by subtracting the output of one function from another.
Product of functions
The function obtained by multiplying the outputs of two functions.
Quotient of functions
The function obtained by dividing one function output by another, wherever the denominator is non-zero.

Important formulas

Addition: (f + g)(x) = f(x) + g(x)

Subtraction: (f - g)(x) = f(x) - g(x)

Multiplication: (fg)(x) = f(x) × g(x)

Division: (f/g)(x) = f(x)/g(x), where g(x) ≠ 0

Common domain: For sum, difference and product, use Domain(f) ∩ Domain(g).

Quotient domain: Use the common domain and exclude values where g(x) = 0.

REFERENCE 05

Composition of Functions

Important definitions

Composition
Composition combines two functions by using the output of one function as the input of another.
Inner function
The function applied first during composition.
Outer function
The function applied to the output of the inner function.
Order of composition
The order matters in general. Composing f after g does not necessarily give the same result as composing g after f.

Important formulas

Composition: (f ∘ g)(x) = f(g(x))

Reverse order: (g ∘ f)(x) = g(f(x))

Identity property: (f ∘ I)(x) = (I ∘ f)(x) = f(x)

Associative property: f ∘ (g ∘ h) = (f ∘ g) ∘ h

Domain condition: x must belong to Domain(g), and g(x) must belong to Domain(f).

Example: If f(x) = x² and g(x) = x + 1, then (f ∘ g)(x) = (x + 1)².

REFERENCE 06

Inverse Functions

Important definitions

Inverse function
The inverse reverses the mapping of a function. It maps an output of the original function back to its corresponding input.
Invertible function
A function has an inverse function from its range to its domain when it is one-one. For an inverse from the entire codomain, it must be bijective.
Inverse notation
f⁻¹ denotes the inverse function. It does not mean 1/f(x).

Important formulas and properties

Inverse property: f⁻¹(f(x)) = x

Reverse inverse property: f(f⁻¹(y)) = y

Domain of inverse: Range of f

Range of inverse: Domain of f

Graph property: The graphs of f and f⁻¹ are reflections across the line y = x.

Finding an inverse: Write y = f(x), interchange x and y, then solve for y.

Example: If f(x) = 2x + 3, then f⁻¹(x) = (x - 3)/2.

REFERENCE 07

Standard Functions and Their Formulas

Important definitions

Linear function
A function whose graph is a straight line.
Quadratic function
A polynomial function of degree two.
Modulus function
A function that gives the non-negative magnitude of a real number.
Reciprocal function
A function that assigns the reciprocal of a non-zero input.
Exponential function
A function in which the variable appears in the exponent.
Logarithmic function
The inverse of an exponential function for a valid base.
Trigonometric functions
Functions that relate angles to ratios of sides in a right-angled triangle and extend periodically to real inputs.

Formula reference

Linear: f(x) = mx + c

Quadratic: f(x) = ax² + bx + c, where a ≠ 0

Modulus: f(x) = |x|

Reciprocal: f(x) = 1/x, where x ≠ 0

Square root: f(x) = √x, where x ≥ 0

Exponential: f(x) = aˣ, where a > 0 and a ≠ 1

Logarithmic: f(x) = logₐ(x), where a > 0, a ≠ 1 and x > 0

Sine: f(x) = sin x

Cosine: f(x) = cos x

Tangent: f(x) = tan x, where x ≠ (2n + 1)π/2 for integer n

Quadratic discriminant: D = b² - 4ac

Quadratic roots: x = (-b ± √D)/(2a)
