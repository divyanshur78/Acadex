EXAMPLE 01 · BEGINNER

Identifying a Function from a Relation

Unit 01 · Introduction to Functions

Problem

Consider the relation R = {(1, 2), (2, 4), (3, 6), (4, 8)}. Determine whether R represents a function. Also identify its domain and range.

Solution

  1. Recall that a relation is a function if every input has exactly one output.
  2. Identify the first elements of the ordered pairs: 1, 2, 3 and 4.
  3. Each input appears only once and is associated with exactly one output.
  4. Therefore, the relation satisfies the definition of a function.
  5. The domain is the set of first elements: {1, 2, 3, 4}.
  6. The range is the set of second elements: {2, 4, 6, 8}.
View final answer and explanation

Final answer: R is a function.

Domain: {1, 2, 3, 4}

Range: {2, 4, 6, 8}

Remember: Repeated outputs are allowed in a function. What is not allowed is one input having two different outputs.

EXAMPLE 02 · BEGINNER

Finding the Domain of a Rational Function

Unit 01 · Domain and Range

Problem

Find the domain of f(x) = (x + 3)/(x - 2).

Solution

  1. The given function is a rational function.
  2. A rational function is undefined when its denominator is zero.
  3. Set the denominator equal to zero: x - 2 = 0.
  4. Solving gives x = 2.
  5. Therefore, every real number is allowed except x = 2.
View final answer and explanation

Final answer: Domain = R − {2}

In interval notation: (-∞, 2) ∪ (2, ∞).

Remember: Always check the denominator of a rational function before deciding its domain.

EXAMPLE 03 · BEGINNER

Finding the Domain and Range of a Square Root Function

Unit 01 · Domain and Range Restrictions

Problem

Find the domain and range of f(x) = √(x - 4) + 2.

Solution

  1. For a real-valued square root, the expression inside the root must be greater than or equal to zero.
  2. Write the restriction: x - 4 ≥ 0.
  3. Solving gives x ≥ 4. This is the domain restriction.
  4. The square root value is always non-negative: √(x - 4) ≥ 0.
  5. Adding 2 gives f(x) ≥ 2.
  6. The minimum output is 2, attained when x = 4. As x increases, the output has no upper bound.
View final answer and explanation

Domain: [4, ∞)

Range: [2, ∞)

Check: At x = 4, f(4) = √0 + 2 = 2.

Remember: For an even root, the radicand must be non-negative. The square root itself is also non-negative.

EXAMPLE 04 · INTERMEDIATE

Testing Whether a Function is One-One and Onto

Unit 01 · Types of Functions

Problem

Let f : R → R be defined by f(x) = 2x + 5. Determine whether the function is one-one and onto.

Solution

  1. Test for one-one: Assume f(a) = f(b).
  2. Then 2a + 5 = 2b + 5.
  3. Subtract 5 from both sides: 2a = 2b.
  4. Divide by 2: a = b. Therefore, f is one-one.
  5. Test for onto: Let y be any real number in the codomain.
  6. Write y = 2x + 5.
  7. Solving for x gives x = (y - 5)/2.
  8. Since y is real, the calculated x is also real and belongs to the domain.
  9. Thus every real number in the codomain has a preimage. The function is onto.
View final answer and explanation

One-one: Yes.

Onto: Yes.

Final classification: Bijective.

Remember: A function is bijective only when it satisfies both the one-one and onto conditions.

EXAMPLE 05 · INTERMEDIATE

Operations on Two Functions

Unit 01 · Addition, Subtraction and Multiplication

Problem

Given f(x) = x² + 2x and g(x) = 3x - 1, find (f + g)(x), (f - g)(x), (fg)(x) and (f/g)(x), along with the domain of the quotient.

Solution

  1. Addition: (f + g)(x) = x² + 2x + 3x - 1 = x² + 5x - 1.
  2. Subtraction: (f - g)(x) = x² + 2x - (3x - 1) = x² - x + 1.
  3. Multiplication: (fg)(x) = (x² + 2x)(3x - 1).
  4. Expand: 3x³ - x² + 6x² - 2x = 3x³ + 5x² - 2x.
  5. Division: (f/g)(x) = (x² + 2x)/(3x - 1).
  6. For the quotient, the denominator must not be zero: 3x - 1 ≠ 0.
  7. Solving gives x ≠ 1/3.
View final answer and explanation

(f + g)(x): x² + 5x - 1

(f - g)(x): x² - x + 1

(fg)(x): 3x³ + 5x² - 2x

(f/g)(x): (x² + 2x)/(3x - 1)

Quotient domain: R − {1/3}

Remember: The quotient excludes every input that makes the denominator function zero.

EXAMPLE 06 · INTERMEDIATE

Finding the Composition of Functions

Unit 01 · Composition of Functions

Problem

Let f(x) = x² + 1 and g(x) = 2x - 3. Find (f ∘ g)(x) and (g ∘ f)(x). Are the two compositions equal?

Solution

  1. First composition: (f ∘ g)(x) = f(g(x)).
  2. Substitute g(x) = 2x - 3 into f: (f ∘ g)(x) = (2x - 3)² + 1.
  3. Expand: 4x² - 12x + 9 + 1 = 4x² - 12x + 10.
  4. Second composition: (g ∘ f)(x) = g(f(x)).
  5. Substitute f(x) = x² + 1 into g: (g ∘ f)(x) = 2(x² + 1) - 3.
  6. Simplify: 2x² + 2 - 3 = 2x² - 1.
  7. Compare the two expressions. They are different, so composition is not commutative in general.
View final answer and explanation

(f ∘ g)(x): 4x² - 12x + 10

(g ∘ f)(x): 2x² - 1

Conclusion: (f ∘ g)(x) ≠ (g ∘ f)(x).

Remember: In f ∘ g, apply g first and then f. Always follow the order from inside to outside.

EXAMPLE 07 · ADVANCED

Finding the Inverse of a Function

Unit 01 · Inverse Functions

Problem

Find the inverse of f(x) = (3x - 4)/2. Verify the result using composition.

Solution

  1. Write the function as y = (3x - 4)/2.
  2. Interchange x and y: x = (3y - 4)/2.
  3. Multiply both sides by 2: 2x = 3y - 4.
  4. Add 4 to both sides: 2x + 4 = 3y.
  5. Divide by 3: y = (2x + 4)/3.
  6. Therefore, f⁻¹(x) = (2x + 4)/3.
  7. Verification: Substitute f⁻¹(x) into f.
  8. f(f⁻¹(x)) = [3((2x + 4)/3) - 4]/2.
  9. Simplify: [(2x + 4) - 4]/2 = 2x/2 = x.
  10. The composition gives x, confirming the inverse.
View final answer and explanation

Inverse: f⁻¹(x) = (2x + 4)/3

Verification: f(f⁻¹(x)) = x.

Domain of f: R

Range of f: R

Domain and range of f⁻¹: Both R.

Remember: Interchange x and y, solve for y, and verify by composition. The inverse notation f⁻¹(x) does not mean 1/f(x).
