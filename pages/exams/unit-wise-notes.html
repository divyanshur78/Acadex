UNIT 01 · CHAPTER 01

Introduction to Functions

Understand mathematical functions, their inputs and outputs, domain, codomain, range and important classifications. This chapter builds the foundation required for limits and continuity.

01. Meaning and Definition of a Function

1.1 What is a Function?

A function is a mathematical relation that assigns exactly one output to every valid input. The same output may be assigned to different inputs, but one input cannot have two different outputs in a function.

General notation

f : A → B

For every x ∈ A, there is exactly one y ∈ B such that y = f(x).

1.2 Understanding Function Notation

Consider the function:

Example function

f(x) = 2x + 3

When x = 2:

f(2) = 2(2) + 3 = 7

When x = 5:

f(5) = 2(5) + 3 = 13

Therefore, the function takes an input, applies the mathematical rule and produces one corresponding output.

1.3 Relations and Functions

A relation is a collection of ordered pairs. A relation becomes a function when every input in its domain has exactly one corresponding output.

  • One input cannot be associated with two different outputs.
  • Different inputs are allowed to have the same output.
  • Every element of the domain must have an output.
Example

{(1, 2), (2, 4), (3, 6)} represents a function.

{(1, 2), (1, 5), (3, 6)} does not represent a function because input 1 has two outputs.

02. Domain, Codomain and Range

2.1 Domain

The domain is the set of all permitted input values for which the function is defined.

2.2 Codomain

The codomain is the declared set in which the outputs of a function are expected to lie.

2.3 Range

The range is the set of actual output values produced by the function for all inputs in its domain.

Important relationship

Range ⊆ Codomain

2.4 Worked Example

Consider:

f : A → B

A = {-2, -1, 0, 1, 2}

B = {0, 1, 2, 3, 4, 5}

f(x) = x²

The input-output pairs are:

f(-2) = 4

f(-1) = 1

f(0) = 0

f(1) = 1

f(2) = 4

  • Domain = {-2, -1, 0, 1, 2}
  • Codomain = {0, 1, 2, 3, 4, 5}
  • Range = {0, 1, 4}
Remember

The range contains only the values actually obtained. Values 2, 3 and 5 belong to the codomain but are not produced by this particular function.

03. Finding the Domain of a Function

To find a domain, identify values that make the expression undefined or invalid in the real number system.

3.1 Polynomial Functions

f(x) = x² + 3x + 5

A polynomial is defined for every real number.

Domain: R

3.2 Rational Functions

The denominator of a fraction must not be zero.

f(x) = 1 / (x - 4)

x - 4 ≠ 0

x ≠ 4

Domain: R \ {4}

3.3 Square Root Functions

For a real-valued square root, the expression inside the square root must be greater than or equal to zero.

f(x) = √(x - 3)

x - 3 ≥ 0

x ≥ 3

Domain: [3, ∞)

3.4 Logarithmic Functions

The argument of a real logarithmic function must be strictly positive.

f(x) = log(x + 2)

x + 2 > 0

x > -2

Domain: (-2, ∞)

Exam tip

Check denominators, square-root expressions and logarithmic arguments before writing the final domain.

04. Types of Functions

4.1 One-One (Injective) Function

A function is one-one if different inputs always produce different outputs.

f(a) = f(b) ⇒ a = b

4.2 Many-One Function

A function is many-one when two or more different inputs can produce the same output.

Example

f(x) = x² over R.

f(2) = 4 and f(-2) = 4.

4.3 Onto (Surjective) Function

A function is onto when every element of its codomain is the output of at least one element of its domain.

Range = Codomain

4.4 Into Function

A function is into when at least one element of its codomain is not mapped by any element of the domain.

Range is a proper subset of Codomain.

4.5 Bijective Function

A function is bijective when it is both one-one and onto.

Important distinction

One-one describes whether outputs repeat. Onto describes whether the entire codomain is reached.

05. Operations and Composition of Functions

Functions can be combined using arithmetic operations and composition.

5.1 Addition

(f + g)(x) = f(x) + g(x)

5.2 Subtraction

(f - g)(x) = f(x) - g(x)

5.3 Multiplication

(fg)(x) = f(x) × g(x)

5.4 Division

(f / g)(x) = f(x) / g(x), where g(x) ≠ 0

5.5 Composition of Functions

Composition means applying one function to the output of another function.

(f ∘ g)(x) = f(g(x))

Worked example

Let f(x) = 2x + 1 and g(x) = x².

(f ∘ g)(x) = f(g(x))

= f(x²)

= 2x² + 1

(g ∘ f)(x) = g(2x + 1)

= (2x + 1)²

= 4x² + 4x + 1

Composition is generally not commutative: f ∘ g need not equal g ∘ f.

06. Inverse Functions

An inverse function reverses the mapping performed by the original function.

f⁻¹(f(x)) = x

f(f⁻¹(x)) = x

A function must be bijective from its domain to its codomain to have an inverse function over that entire domain and codomain.

Worked Example

Find the inverse of:

f(x) = 2x + 3

Step 1: Write y = f(x).

y = 2x + 3

Step 2: Interchange x and y.

x = 2y + 3

Step 3: Solve for y.

2y = x - 3

y = (x - 3) / 2

Final answer:

f⁻¹(x) = (x - 3) / 2

07. Standard Functions and Their Behaviour

7.1 Constant Function

f(x) = c

Every input produces the same constant output.

7.2 Identity Function

f(x) = x

The output is equal to the input.

7.3 Linear Function

f(x) = mx + c

Its graph is a straight line.

7.4 Quadratic Function

f(x) = ax² + bx + c, where a ≠ 0

Its graph is a parabola.

7.5 Modulus Function

f(x) = |x|

f(x) = x, when x ≥ 0

f(x) = -x, when x < 0

7.6 Exponential Function

f(x) = aˣ, where a > 0 and a ≠ 1

7.7 Logarithmic Function

f(x) = logₐ(x), where a > 0 and a ≠ 1

Domain: x > 0

7.8 Trigonometric Functions

sin x, cos x, tan x

These functions describe relationships involving angles and are important in the study of limits and calculus.

Connection to the next chapter

Understanding function notation, domain and standard function behaviour will help you understand limits, continuity and differentiability.
