Linear Algebra: Matrices and Rank

Detailed concept notes
Matrix

A matrix is a rectangular arrangement of elements in rows and columns. Its order is m × n when it contains m rows and n columns.

Rank

The rank is the maximum number of linearly independent rows or columns. It equals the number of pivots in row-echelon form.

Elementary row operations

Interchanging rows, multiplying a row by a non-zero scalar, and adding a multiple of one row to another preserve rank.

Linear systems

A system Ax = b is consistent when the rank of A equals the rank of its augmented matrix [A|b]. A unique solution additionally requires that rank equal the number of unknowns.

Important formulas and quick reference
  • rank(A) ≤ min(m,n).
  • rank(Iₙ) = n.
  • For an invertible square matrix, rank(A) = n.
  • Consistency: rank(A) = rank([A|b]).
Worked example

Find the rank of the 2 × 2 identity matrix.

  1. Its rows are (1,0) and (0,1).
  2. Neither row is a scalar multiple of the other.
  3. Both are independent, so rank = 2.
Topic-wise practice

Attempt the questions before revealing their solutions.

Beginner

Question 1: Rank of a 3 × 3 identity matrix?

  1. A. 0
  2. B. 1
  3. C. 2
  4. D. 3
Reveal answer and explanation
Answer: 3

All three rows are linearly independent.

Intermediate

Question 2: Maximum possible rank of a 3 × 5 matrix?

  1. A. 2
  2. B. 3
  3. C. 5
  4. D. 8
Reveal answer and explanation
Answer: 3

Rank cannot exceed the smaller matrix dimension.

Advanced

Question 3: If a square matrix has non-zero determinant, its rank is:

  1. A. 0
  2. B. 1
  3. C. Less than n
  4. D. n
Reveal answer and explanation
Answer: n

A non-zero determinant implies invertibility and full rank.

Exam

Question 4: A system is inconsistent when:

  1. A. rank(A) = rank([A|b])
  2. B. rank(A) < rank([A|b])
  3. C. Both ranks are zero
  4. D. A is square
Reveal answer and explanation
Answer: rank(A) < rank([A|b])

The augmented matrix has greater rank than the coefficient matrix.

CORE

Calculus: Integration

Detailed concept notes
Antiderivatives

Integration reverses differentiation. An indefinite integral represents a family of antiderivatives and includes a constant of integration.

Standard integrals

Power functions, exponential functions and trigonometric functions have standard antiderivatives.

Definite integrals

A definite integral over an interval gives the signed accumulation of a function. The fundamental theorem of calculus connects definite integration with antiderivatives.

Methods

Substitution simplifies composite expressions. Integration by parts is useful for products of functions.

Important formulas and quick reference
  • ∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ -1.
  • ∫1/x dx = ln|x| + C.
  • ∫eˣ dx = eˣ + C.
  • ∫ₐᵇ f(x)dx = F(b) - F(a).
Worked example

Evaluate ∫(3x² + 2) dx.

  1. Integrate each term.
  2. ∫3x² dx = x³.
  3. ∫2 dx = 2x.
  4. Result: x³ + 2x + C.
Topic-wise practice

Attempt the questions before revealing their solutions.

Beginner

Question 1: ∫2x dx equals:

  1. A. 2x² + C
  2. B. x² + C
  3. C. x + C
  4. D. 2 + C
Reveal answer and explanation
Answer: x² + C

The antiderivative of 2x is x².

Intermediate

Question 2: ∫₀¹ 2x dx equals:

  1. A. 0
  2. B. 1
  3. C. 2
  4. D. 4
Reveal answer and explanation
Answer: 1

Antiderivative is x²; evaluate 1² - 0².

Advanced

Question 3: Which method is commonly suitable for ∫x eˣ dx?

  1. A. Partial fractions
  2. B. Integration by parts
  3. C. Row reduction
  4. D. Cramer's rule
Reveal answer and explanation
Answer: Integration by parts

The integrand is a product of two functions.

Exam

Question 4: The constant of integration is needed in:

  1. A. Every derivative
  2. B. Indefinite integration
  3. C. Only matrix operations
  4. D. Only limits
Reveal answer and explanation
Answer: Indefinite integration

All antiderivatives differ by a constant.

Quantitative Aptitude: Percentages and Ratios

Detailed concept notes
Percentages

A percentage expresses a quantity per hundred. Convert a percentage to a fraction by dividing by 100.

Percentage change

Compare the change with the original value, not the final value. An increase and a decrease of the same percentage do not generally cancel.

Ratios

A ratio a:b compares quantities in the same units. If the total is known, add the ratio parts and divide the total by that sum.

Important formulas and quick reference
  • x% of N = xN/100.
  • Percentage change = (change/original) × 100.
  • If a:b and total T, first share = aT/(a+b).
Worked example

Divide 360 in the ratio 5:7.

  1. Total parts = 12.
  2. One part = 360/12 = 30.
  3. Shares = 150 and 210.
Topic-wise practice

Attempt the questions before revealing their solutions.

Beginner

Question 1: 25% of 200 is:

  1. A. 25
  2. B. 40
  3. C. 50
  4. D. 75
Reveal answer and explanation
Answer: 50

200 × 25/100 = 50.

Intermediate

Question 2: Divide 80 in ratio 3:5. Smaller share?

  1. A. 20
  2. B. 30
  3. C. 40
  4. D. 50
Reveal answer and explanation
Answer: 30

Eight parts; each is 10; smaller share is 3 × 10.

Advanced

Question 3: A value rises from 80 to 100. Percentage increase?

  1. A. 20%
  2. B. 25%
  3. C. 30%
  4. D. 40%
Reveal answer and explanation
Answer: 25%

Increase is 20; 20/80 × 100 = 25%.

Exam

Question 4: If A:B = 2:3 and B:C = 4:5, A:C is:

  1. A. 8:15
  2. B. 2:5
  3. C. 4:15
  4. D. 6:5
Reveal answer and explanation
Answer: 8:15

Make B common: 8:12 and 12:15, so A:C = 8:15.
