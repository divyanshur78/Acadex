CONCEPT 01

Meaning of a Function

A function assigns exactly one output to every valid input in its domain.

Read complete summary

Definition

A function is a relation in which every element of the domain is associated with exactly one element of the codomain.

f : A → B

y = f(x)

Remember

  • Every valid input must have an output.
  • One input cannot have two different outputs.
  • Different inputs may produce the same output.
Example:

For f(x) = 2x + 3, f(2) = 7.

CONCEPT 02

Domain, Codomain and Range

Domain means permitted inputs, codomain means the declared output set, and range means actual outputs.

Read complete summary
  • Domain: Set of all permitted inputs.
  • Codomain: Declared set containing possible outputs.
  • Range: Set of outputs actually obtained.

Range ⊆ Codomain

Example:

For f(x) = x² with domain R and codomain R, the range is [0, ∞).

Negative real numbers belong to the codomain but are not produced by squaring a real number.

CONCEPT 03

Rules for Finding the Domain

Check denominators, square-root expressions and logarithmic arguments to identify invalid inputs.

Read complete summary

Important rules

  • Polynomial: all real numbers.
  • Rational function: denominator cannot be zero.
  • Even root: expression inside the root must be ≥ 0.
  • Logarithm: argument must be greater than 0.

1 / (x - 2): x ≠ 2

√(x - 5): x ≥ 5

log(x + 1): x > -1

Revision tip:

Always solve the restriction before writing the domain.

CONCEPT 04

Types of Functions

One-one, many-one, onto, into and bijective functions describe how domain elements map to codomain elements.

Read complete summary
  • One-one: Different inputs produce different outputs.
  • Many-one: Different inputs can produce the same output.
  • Onto: Range equals codomain.
  • Into: At least one codomain element is not reached.
  • Bijective: Both one-one and onto.

One-one: f(a) = f(b) ⇒ a = b

Onto: Range = Codomain

Bijective = One-one + Onto

CONCEPT 05

Operations and Composition

Functions can be combined through arithmetic operations or by applying one function to another.

Read complete summary

(f + g)(x) = f(x) + g(x)

(f - g)(x) = f(x) - g(x)

(fg)(x) = f(x)g(x)

(f/g)(x) = f(x)/g(x), g(x) ≠ 0

(f ∘ g)(x) = f(g(x))

Example:

Let f(x) = 2x + 1 and g(x) = x².

(f ∘ g)(x) = 2x² + 1.

(g ∘ f)(x) = (2x + 1)².

Remember:

Function composition is generally not commutative.

CONCEPT 06

Inverse Functions

An inverse function reverses the mapping of the original function.

Read complete summary

f⁻¹(f(x)) = x

f(f⁻¹(x)) = x

How to find an inverse

  1. Write y = f(x).
  2. Interchange x and y.
  3. Solve the equation for y.
  4. Write the result as f⁻¹(x).
Example:

f(x) = 2x + 3

Interchanging variables gives x = 2y + 3.

Therefore, f⁻¹(x) = (x - 3)/2.

A function needs to be bijective to have an inverse over its entire declared domain and codomain.

CONCEPT 07

Standard Functions

Recognise common function families and their basic mathematical behaviour.

Read complete summary

Constant: f(x) = c

Identity: f(x) = x

Linear: f(x) = mx + c

Quadratic: f(x) = ax² + bx + c

Modulus: f(x) = |x|

Exponential: f(x) = aˣ

Logarithmic: f(x) = logₐ(x)

Trigonometric: sin x, cos x, tan x

  • Linear functions have straight-line graphs.
  • Quadratic functions have parabolic graphs.
  • The modulus function produces non-negative outputs.
  • Exponential and logarithmic functions are closely related through inverse operations.
  • Trigonometric functions are important in calculus and limits.
