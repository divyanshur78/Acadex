Functions and Limits â€“ Understanding Inputs and Outputs

  • Function: A function takes an input and produces exactly one output for that input. Think of it like a machine: you give it a value, and it returns a result.
  • Domain and Range: The domain is the set of values you are allowed to put into a function. The range is the set of outputs the function can produce.
  • Limit: A limit tells us what value a function gets closer to as the input approaches a particular number. The function does not necessarily have to equal that value at the exact point.
  • Finding polynomial limits: For a polynomial expression, you can usually find the limit by directly replacing the variable with the given value and simplifying.

Differentiation â€“ Important Rules

  • Power Rule: When differentiating a power of x, bring the exponent in front and reduce it by one.

    Example: If y = xÂ³, its derivative is 3xÂ².

    Rule: \(\frac{d}{dx}x^n=nx^{n-1}\)

  • Product Rule: Use this when two functions are multiplied. Differentiate the first function and multiply it by the second, then add the first function multiplied by the derivative of the second.

    Rule: \((uv)'=u'v+uv'\)

  • Quotient Rule: Use this when one function is divided by another. Multiply the denominator by the derivative of the numerator, subtract the numerator multiplied by the derivative of the denominator, and divide by the denominator squared.

    Rule: \((u/v)'=(vu'-uv')/v^2\)

  • What does a derivative mean? A derivative tells us how quickly something changes at a particular moment. On a graph, it represents the slope of the tangent at a point.

    Example: In motion, the derivative of position with respect to time gives instantaneous velocity.

Matrices

  • Matrix order: It tells us how many rows and columns a matrix contains. For example, a matrix with 2 rows and 3 columns has order 2 Ã— 3.
  • Matrix addition: Two matrices can be added only when they have the same number of rows and columns. Add the corresponding entries to get the answer.
  • Determinant: A square matrix can have an inverse only when its determinant is not zero. A determinant of zero means the matrix is singular and has no inverse.
  • Rank: Rank tells us how many independent rows or columns a matrix contains. In simple terms, it measures how much unique information the matrix has.

Complexity and Searching

  • Constant time â€“ O(1): The operation takes roughly the same amount of time regardless of how many items are stored. Example: accessing an array element using its index.
  • Logarithmic time â€“ O(log n): The amount of work grows slowly because the problem is repeatedly divided into smaller parts. Example: binary search in a sorted list.
  • Linear time â€“ O(n): The work increases with the number of items. If the number of items doubles, the work may roughly double. Example: checking every item in a list.
  • O(n log n): This is a common time complexity for efficient sorting algorithms. The work grows faster than linear time but generally much more slowly than quadratic time.
  • Quadratic time â€“ O(n squared): This often occurs when one loop runs inside another loop. If the input size doubles, the number of operations may become roughly four times larger.
  • Binary Search: This method works only on sorted data. It checks the middle element and repeatedly removes half of the remaining search area. Its time complexity is logarithmic, written as O(log n).

Linear Data Structures

  • Array: A collection of elements stored in an indexed sequence. Each element can be accessed using its position or index.
  • Stack â€“ LIFO (Last In, First Out): The last item added is the first one removed. Imagine a stack of plates: you normally take the top plate first.
  • Queue â€“ FIFO (First In, First Out): The first item added is the first one removed. It works like a queue of people waiting for their turn.
  • Linked List: A sequence of nodes where each node stores data and a reference to the next node. Unlike a typical array, its elements do not need to be stored next to each other in memory.
  • Push and Pop: Push adds a new item to the top of a stack. Pop removes the item currently at the top.

For a stack receiving A, B and C in that order, the first item removed is C because the stack follows LIFO.

04Database Management SystemsSQL Â· Keys Â· Normalisationï¼‹

Database Fundamentals

  • Database: An organised collection of information that makes storing, searching, updating and managing data easier.
  • Primary Key: A column, or combination of columns, that uniquely identifies every record in a table. It cannot contain duplicate or NULL values.
  • Foreign Key: A column that connects one table to another by referring to a key in the related table. It helps maintain relationships between records.
  • Candidate Key: A minimal column or combination of columns that can uniquely identify a record. One candidate key is selected as the primary key.

SQL and Normalisation

  • Basic SQL Commands: SELECT reads information, INSERT adds new records, UPDATE changes existing records, and DELETE removes records from a table.
  • WHERE and ORDER BY: WHERE displays only records that match a condition. ORDER BY arranges the results in ascending or descending order.
  • GROUP BY: It collects records with the same value into groups. It is commonly used with calculations such as COUNT, SUM and AVG.
  • First Normal Form (1NF): Each table cell should contain a single, indivisible value. Avoid storing multiple unrelated values in one cell or repeating groups of columns.
  • Normalisation: The process of organising database tables to reduce repeated information and prevent problems when records are inserted, updated or deleted.
Worked example

SELECT name FROM Students WHERE marks > 80; retrieves names of students whose marks exceed 80.

05Operating SystemsProcesses Â· Memory Â· Schedulingï¼‹

Processes and Threads

  • Process: A program that is currently running. It has its own execution state and resources managed by the operating system.
  • Thread: A smaller unit of execution inside a process. Multiple threads can work within the same process and share many of its resources.
  • Context Switching: The operating system saves the current task's state and switches the CPU to another task. This allows multiple programs to share CPU time.
  • CPU Scheduling: The operating system decides which waiting process should use the CPU next and for how long.

Memory and Deadlocks

  • RAM (Random Access Memory): Temporary working memory used by programs while they are running. Its contents are normally lost when the computer is switched off.
  • Virtual Memory: A memory-management technique that gives each process its own address space. The operating system manages how virtual addresses relate to physical memory.
  • Paging: Memory is divided into fixed-size blocks. The process's blocks are called pages, while the corresponding blocks in physical memory are called frames.
  • Deadlock: A situation where two or more processes are stuck waiting for resources held by one another, so none of them can continue.
  • Four Deadlock Conditions: Mutual exclusion means a resource cannot be shared at the same time; hold and wait means a process holds one resource while requesting another; no preemption means resources cannot simply be taken away; circular wait means processes form a cycle of waiting.
Worked example

Round Robin scheduling gives each ready process a time slice before moving to the next process.

Moderate Â· Question 2

Answer: Round Robin. Each process receives a fixed time slice.

06Computer NetworksOSI Â· TCP/IP Â· Protocolsï¼‹

Network Models

  • OSI Model: The Open Systems Interconnection model explains network communication in seven layers: Physical, Data Link, Network, Transport, Session, Presentation and Application. Each layer has a specific responsibility.
  • TCP (Transmission Control Protocol): A transport protocol that establishes a connection and helps deliver data reliably, in the correct order.
  • UDP (User Datagram Protocol): A connectionless transport protocol that sends data without guaranteeing delivery or order. It has less overhead and is useful when speed matters.
  • IP (Internet Protocol): It provides logical addresses and helps route packets from one network to another.

Common Protocols

  • HTTP and HTTPS: Protocols used for communication between browsers and web servers. HTTPS adds encryption to protect the communication.
  • DNS (Domain Name System): It helps convert readable website names into IP addresses that computers use to locate servers.
  • DHCP (Dynamic Host Configuration Protocol): It automatically provides devices with network settings such as an IP address.
  • SMTP (Simple Mail Transfer Protocol): It is commonly used to send outgoing email between mail clients and servers.
  • FTP (File Transfer Protocol): A protocol designed to transfer files between computers over a network.
Worked example

When a user enters a domain name, DNS helps find its corresponding IP address before the device communicates with the destination.
