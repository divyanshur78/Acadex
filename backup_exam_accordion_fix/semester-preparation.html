FOUNDATION

Functions, Limits and Continuity

Detailed concept notes
1. Functions

A function assigns exactly one output to each permitted input. The set of permitted inputs is the domain, while the set of resulting outputs is the range.

For example, f(x) = x² maps each real number to its square. Its domain is all real numbers and its range is non-negative real numbers.

2. Limits

A limit describes the value a function approaches as its input approaches a particular point. The function does not necessarily need to be defined at that point.

For polynomial functions, direct substitution is often sufficient. For indeterminate forms such as 0/0, factorisation or other limit techniques may be needed.

3. Continuity

A function is continuous at x = a when its limit exists there and equals its function value. Graphically, there is no break at that point.

Important formulas and quick reference
  • For a polynomial, lim x→a f(x) = f(a).
  • Continuity at a: lim x→a f(x) = f(a).
  • For a product: lim(fg) = (lim f)(lim g), when the limits exist.
Worked example

Evaluate lim x→2 (x² + 3x).

  1. Substitute x = 2 because the expression is a polynomial.
  2. 2² + 3(2) = 4 + 6.
  3. The limit is 10.

Attempt the questions before revealing their solutions.

Beginner

Question 1: Evaluate lim x→2 (x + 4)

  1. A. 4
  2. B. 5
  3. C. 6
  4. D. 8
Reveal answer and explanation
Answer: 6

Substitution gives 2 + 4 = 6.

Intermediate

Question 2: What is the domain of f(x) = 1/x?

  1. A. All real numbers
  2. B. All real numbers except 0
  3. C. Only positive numbers
  4. D. Only integers
Reveal answer and explanation
Answer: All real numbers except 0

Division by zero is undefined.

Advanced

Question 3: For continuity at x = a, which equality must hold?

  1. A. f(a) = 0
  2. B. Limit = f(a)
  3. C. Derivative = 0
  4. D. Domain is empty
Reveal answer and explanation
Answer: Limit = f(a)

The limit must exist and equal the function value.

Exam

Question 4: Evaluate lim x→3 (x² - 9)/(x - 3).

  1. A. 3
  2. B. 6
  3. C. 9
  4. D. 12
Reveal answer and explanation
Answer: 6

Factorise: (x - 3)(x + 3)/(x - 3), then substitute 3.

CORE CONCEPT

Differentiation and Applications

Detailed concept notes
1. Meaning of differentiation

The derivative measures the instantaneous rate of change of a function. Geometrically, it represents the slope of the tangent to the curve at a point.

2. Power rule

For x raised to a constant power n, bring the exponent down as a multiplier and reduce the exponent by one.

3. Product and chain rules

The product rule is used when two differentiable functions are multiplied. The chain rule is used for composite functions, where one function is inside another.

4. Applications

Derivatives are used to determine increasing or decreasing intervals, stationary points, rates of change and optimisation.

Important formulas and quick reference
  • d(xⁿ)/dx = nxⁿ⁻¹
  • d(c)/dx = 0
  • d(u + v)/dx = u' + v'
  • d(uv)/dx = u'v + uv'
  • d(f(g(x)))/dx = f'(g(x))g'(x)
Worked example

Differentiate y = 3x⁴ - 2x² + 5.

  1. Differentiate each term separately.
  2. 3 × 4x³ - 2 × 2x.
  3. Therefore dy/dx = 12x³ - 4x.
Topic-wise practice

Attempt the questions before revealing their solutions.

Beginner

Question 1: Derivative of x⁵?

  1. A. x⁴
  2. B. 5x⁴
  3. C. 5x
  4. D. x⁶
Reveal answer and explanation
Answer: 5x⁴

Apply the power rule.

Intermediate

Question 2: Derivative of 7x - 9?

  1. A. 7
  2. B. 7x
  3. C. -9
  4. D. 0
Reveal answer and explanation
Answer: 7

The derivative of 7x is 7 and the derivative of a constant is zero.

Advanced

Question 3: Derivative of (x² + 1)³?

  1. A. 3(x² + 1)²
  2. B. 6x(x² + 1)²
  3. C. 2x(x² + 1)
  4. D. 3x²
Reveal answer and explanation
Answer: 6x(x² + 1)²

Use the chain rule: 3(x² + 1)² × 2x.

Exam

Question 4: At a stationary point, the first derivative is generally:

  1. A. 1
  2. B. -1
  3. C. 0
  4. D. Undefined
Reveal answer and explanation
Answer: 0

A differentiable function has a stationary point where its first derivative is zero.

FOUNDATION

Variables, Data Types and Control Flow

Detailed concept notes
Variables

A variable is a named reference used to work with a value. In Python, a variable is created by assignment, such as count = 10.

Data types

Common Python types include int, float, str and bool. Lists store ordered collections, tuples are immutable sequences, and dictionaries store key-value pairs.

Control flow

Conditional statements choose which block executes. Loops repeat a block while a condition holds or for each item in an iterable.

Functions

Functions package reusable instructions. Parameters receive input values, and return sends a result back to the caller.

Important formulas and quick reference
  • if / elif / else: conditional execution.
  • for: iteration over an iterable.
  • while: repetition while a condition is true.
  • def: function definition.
Worked example

Given marks = [70, 80, 90], calculate the average.

  1. Sum: 70 + 80 + 90 = 240.
  2. Number of values: 3.
  3. Average = 240 / 3 = 80.

  1. A. int
  2. B. str
  3. C. bool
  4. D. list
Reveal answer and explanation
Answer: bool

Boolean values are True and False.

Intermediate

Question 2: Which keyword defines a function in Python?

  1. A. class
  2. B. def
  3. C. return
  4. D. import
Reveal answer and explanation
Answer: def

The def keyword starts a function definition.

Advanced

Question 3: What does range(2, 6) generate?

  1. A. 2,3,4,5,6
  2. B. 2,3,4,5
  3. C. 1,2,3,4,5
  4. D. 2,6
Reveal answer and explanation
Answer: 2,3,4,5

The stop value 6 is excluded.

Exam

Question 4: Which collection is immutable?

  1. A. List
  2. B. Dictionary
  3. C. Set
  4. D. Tuple
Reveal answer and explanation
Answer: Tuple

A tuple cannot be modified after creation.
