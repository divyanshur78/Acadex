Linear Algebra: Matrices and Rank

Detailed concept notes
1. Start with the idea of a matrix

Imagine storing students' marks in a table: each row represents a student and each column represents a subject. A matrix does something similar. It arranges numbers in rows and columns so that calculations involving many values become easier to organise.

A matrix is a rectangular arrangement of elements. If it has m rows and n columns, its order is written as m × n.

Example: A matrix with 2 rows and 3 columns has order 2 × 3. The number of rows is always written first.

2. Elements, rows, columns and notation

A matrix is commonly represented by a capital letter such as A. Its element in row i and column j is written as aij.

For example, in a 2 × 2 matrix, a12 means the element in the first row and second column. Do not confuse the row index with the column index.

3. Important types of matrices
  • Row matrix: Contains exactly one row.
  • Column matrix: Contains exactly one column.
  • Square matrix: Has the same number of rows and columns.
  • Zero matrix: Every element is zero.
  • Diagonal matrix: A square matrix whose entries outside the main diagonal are zero.
  • Scalar matrix: A diagonal matrix in which every diagonal entry is equal.
  • Identity matrix: A diagonal matrix with every diagonal entry equal to 1. It is written as I.
  • Upper triangular matrix: Every entry below the main diagonal is zero.
  • Lower triangular matrix: Every entry above the main diagonal is zero.
  • Symmetric matrix: A square matrix satisfying AT = A.
  • Skew-symmetric matrix: A square matrix satisfying AT = −A. Its diagonal entries must be zero.
4. When can two matrices be added or multiplied?

Addition and subtraction: Both matrices must have the same order. Corresponding elements are added or subtracted.

Scalar multiplication: Every element is multiplied by the same number.

Matrix multiplication: If A has order m × n and B has order n × p, the product AB exists and has order m × p. The inner dimensions must match.

Matrix multiplication is generally not commutative: AB need not equal BA. Even when both products exist, their values may differ.

5. Transpose and inverse

Transpose: The transpose AT is formed by converting rows into columns. A matrix of order m × n becomes one of order n × m.

Inverse: A square matrix A has an inverse A−1 when A A−1 = A−1A = I. A matrix is invertible precisely when its determinant is non-zero.

Not every matrix has an inverse. A non-square matrix does not have an ordinary two-sided matrix inverse.

6. Determinants and their connection with rank

The determinant is a number associated with a square matrix. It helps determine whether the matrix is invertible and whether its rows or columns are linearly independent.

For a 2 × 2 matrix, the determinant is calculated by multiplying the main diagonal entries and subtracting the product of the other diagonal entries.

If the determinant of an n × n matrix is non-zero, its rank is n. If the determinant is zero, the matrix is singular and its rank is less than n.

7. What does rank actually mean?

The rank of a matrix is the maximum number of linearly independent rows or columns. It tells us how much independent information the matrix contains.

Think of a row that can be created by multiplying another row by a constant. It does not add a new independent direction. Such a row does not increase the rank.

Linear independence: A collection of vectors is linearly independent when none of its vectors can be expressed as a linear combination of the others. Otherwise, the collection is linearly dependent.

8. Finding rank using elementary row operations

Row reduction is one of the most useful methods for finding rank. Convert the matrix into row-echelon form and count its non-zero rows, or equivalently, its pivots.

The three permitted elementary row operations are:

  1. Interchange two rows.
  2. Multiply a row by a non-zero constant.
  3. Add a multiple of one row to another row.

These operations preserve the rank. Dividing a row by zero is never permitted.

9. Row-echelon form and reduced row-echelon form

A matrix is in row-echelon form when all zero rows are at the bottom, each leading non-zero entry is to the right of the leading entry in the row above it, and all entries below each leading entry are zero.

In reduced row-echelon form, each leading entry is 1 and is the only non-zero entry in its column.

A leading entry is called a pivot. The number of pivots gives the rank.

10. Worked reasoning: a matrix with dependent rows

Consider the matrix with rows (1, 2, 3), (2, 4, 6), and (1, 1, 1).

  1. The second row is twice the first row, so it is dependent on the first.
  2. Subtract twice the first row from the second row. The second row becomes a zero row.
  3. Subtract the first row from the third row. The third row becomes (0, −1, −2).
  4. There are now two non-zero rows, so the rank is 2.

The original matrix has three rows, but only two independent rows. Therefore, its rank is 2.

11. Rank and systems of linear equations

A system of linear equations can be written as A x = b, where A is the coefficient matrix, x is the vector of unknowns, and b is the constants vector.

The augmented matrix [A | b] is formed by attaching b as an additional column to A.

  • Consistent system: rank(A) = rank([A | b]). At least one solution exists.
  • Inconsistent system: rank(A) ≠ rank([A | b]). No solution exists.
  • Unique solution: For n unknowns, the system is consistent and rank(A) = n.
  • Infinitely many solutions: The system is consistent and rank(A) is less than n.

These conditions are the rank test for consistency. They are especially useful when a system contains parameters or when the number of equations differs from the number of unknowns.

12. Important properties and common mistakes
  • The rank cannot exceed the number of rows or columns: rank(A) ≤ min(m, n).
  • The rank of a zero matrix is zero.
  • The rank of an identity matrix of order n is n.
  • Row operations preserve rank, but arbitrary changes to individual entries do not.
  • For every matrix, row rank equals column rank.
  • Do not conclude that a matrix has full rank merely because it is square.
  • A zero determinant proves that a square matrix is singular, but does not by itself tell you its exact rank.
  • Always check the dimensions before attempting matrix multiplication.
13. Advanced connection: rank and the number of solutions

For a linear transformation represented by an m × n matrix, the rank measures the dimension of its image, while the nullity measures the dimension of its null space.

The rank-nullity theorem states that:

rank(A) + nullity(A) = n

Here, n is the number of columns, or equivalently, the number of variables in the associated homogeneous system. This theorem connects independent output directions with the number of free variables.

14. How to approach a difficult rank question
  1. Check the order of the matrix and identify whether it is square.
  2. Look for obvious zero rows, repeated rows, or scalar multiples.
  3. Use permitted row operations to create zeros below pivots.
  4. Continue until the matrix reaches row-echelon form.
  5. Count the non-zero rows or pivots.
  6. If a system of equations is involved, compare the ranks of the coefficient and augmented matrices.
  7. If a parameter is present, identify the parameter values that change the number of pivots.

Learning checkpoint: You should now be able to explain what rank measures, find it using row reduction, recognise dependent rows, and use rank to determine whether a linear system has no solution, one solution, or infinitely many solutions.

Important formulas and quick reference
  • rank(A) ≤ min(m,n).
  • rank(Iₙ) = n.
  • For an invertible square matrix, rank(A) = n.
  • Consistency: rank(A) = rank([A|b]).
Worked example

Find the rank of the 2 × 2 identity matrix.

  1. Its rows are (1,0) and (0,1).
  2. Neither row is a scalar multiple of the other.
  3. Both are independent, so rank = 2.

Calculus: Integration

Detailed concept notes
1. Understanding integration

Integration is the process of finding an accumulated quantity. It is closely connected to differentiation: differentiation tells us how quickly a quantity changes, while integration helps us recover the original quantity or calculate the total accumulated amount.

If the derivative of a function F(x) is f(x), then an antiderivative of f(x) is F(x).

If F′(x) = f(x), then ∫ f(x) dx = F(x) + C.

Here, C is the constant of integration. It is included because the derivative of every constant is zero.

2. Antiderivatives and the reverse power rule

For a power of x, integration reverses the power rule of differentiation.

∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C, where n ≠ −1.

Increase the exponent by one, then divide by the new exponent.

Example: ∫ x⁴ dx = x⁵/5 + C.

Important exception: When the power is −1, the result is logarithmic:

∫ (1/x) dx = ln|x| + C.

3. Standard integrals to remember
  • ∫ 1 dx = x + C
  • ∫ eˣ dx = eˣ + C
  • ∫ aˣ dx = aˣ/ln(a) + C, for a > 0 and a ≠ 1
  • ∫ sin x dx = −cos x + C
  • ∫ cos x dx = sin x + C
  • ∫ sec² x dx = tan x + C
  • ∫ cosec² x dx = −cot x + C
  • ∫ 1/(1 + x²) dx = tan⁻¹ x + C
  • ∫ 1/√(1 − x²) dx = sin⁻¹ x + C

These standard results are building blocks. Many difficult integrals become manageable after rewriting the expression to match one of these forms.

4. Integration by substitution

Use substitution when an expression contains a function and a multiple of its derivative. Replace the inner expression with a new variable to simplify the integral.

Suppose u = g(x). Then du = g′(x) dx.

Worked example: Evaluate ∫ 2x(x² + 3)⁴ dx.

  1. Choose u = x² + 3.
  2. Differentiate: du = 2x dx.
  3. The integral becomes ∫ u⁴ du.
  4. Integrate: u⁵/5 + C.
  5. Substitute back: (x² + 3)⁵/5 + C.

When to use it: Look for an inner function whose derivative is also present, possibly multiplied by a constant.

5. Integration by parts

Use integration by parts when the integrand is a product of two different types of functions, such as a polynomial multiplied by an exponential, logarithmic or trigonometric function.

∫ u dv = uv − ∫ v du.

The method comes from the product rule of differentiation. Select u and dv, then calculate du and v.

Worked example: Evaluate ∫ x eˣ dx.

  1. Choose u = x and dv = eˣ dx.
  2. Then du = dx and v = eˣ.
  3. Apply the formula: ∫ x eˣ dx = xeˣ − ∫ eˣ dx.
  4. Integrate the remaining term: xeˣ − eˣ + C.
  5. Final answer: eˣ(x − 1) + C.

A useful selection guideline is to choose u so that differentiating it makes it simpler.

6. Integration using partial fractions

Partial fractions are useful when the integrand is a rational function: a polynomial divided by another polynomial. First factor the denominator, then express the fraction as a sum of simpler fractions.

Worked example: Evaluate ∫ 1/[x(x + 1)] dx.

  1. Write 1/[x(x + 1)] = A/x + B/(x + 1).
  2. Multiply through by x(x + 1): 1 = A(x + 1) + Bx.
  3. Comparing coefficients gives A = 1 and B = −1.
  4. Integrate: ∫ [1/x − 1/(x + 1)] dx.
  5. Answer: ln|x| − ln|x + 1| + C.
7. Definite integrals

A definite integral has lower and upper limits. It gives the net accumulated value over an interval and does not require a separate constant of integration in the final evaluation.

∫ₐᵇ f(x) dx = F(b) − F(a), where F′(x) = f(x).

Worked example: Evaluate ∫₀² 3x² dx.

  1. An antiderivative is F(x) = x³.
  2. Substitute the upper limit: F(2) = 8.
  3. Substitute the lower limit: F(0) = 0.
  4. Subtract: 8 − 0 = 8.
8. Important properties of definite integrals
  • ∫ₐᵃ f(x) dx = 0.
  • ∫ₐᵇ f(x) dx = −∫ᵦᵃ f(x) dx.
  • ∫ₐᵇ f(x) dx = ∫ₐᶜ f(x) dx + ∫𝚌ᵇ f(x) dx.
  • For an even function, ∫₋ₐᵃ f(x) dx = 2∫₀ᵃ f(x) dx.
  • For an odd function, ∫₋ₐᵃ f(x) dx = 0.

An even function satisfies f(−x) = f(x); an odd function satisfies f(−x) = −f(x).

9. Area and accumulation interpretation

When f(x) is non-negative on an interval, its definite integral represents the area between its graph and the x-axis over that interval. If the function is negative, the integral counts that portion negatively. Geometric area is therefore not always the same as the signed value of an integral.

Integration is also used to calculate accumulated distance from a velocity function, total change from a rate function, and other quantities built up continuously.

10. Choosing the right method
  • Direct formula: The expression matches a standard integral.
  • Substitution: An inner function and its derivative appear together.
  • By parts: The integrand is a product and one factor becomes simpler after differentiation.
  • Partial fractions: The integrand is a rational function with a factorable denominator.
  • Definite-integral properties: Symmetry or interval properties simplify the calculation.
11. Common mistakes to avoid
  • Forgetting + C in an indefinite integral.
  • Applying the power rule to 1/x instead of using the logarithmic rule.
  • Changing limits incorrectly during substitution.
  • Forgetting to evaluate F(b) − F(a) in a definite integral.
  • Confusing signed integral value with geometric area.
  • Using integration by parts without correctly identifying u and dv.
12. Higher-level problem-solving approach

Before calculating, inspect the structure of the integrand. Check whether it is a standard form, a composite function, a product, or a rational expression. Simplify algebraically where possible. After integrating, differentiate your answer to check whether it reproduces the original integrand.

Important formulas and quick reference
  • ∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ -1.
  • ∫1/x dx = ln|x| + C.
  • ∫eˣ dx = eˣ + C.
  • ∫ₐᵇ f(x)dx = F(b) - F(a).
Worked example

Evaluate ∫(3x² + 2) dx.

  1. Integrate each term.
  2. ∫3x² dx = x³.
  3. ∫2 dx = 2x.
  4. Result: x³ + 2x + C.

Quantitative Aptitude: Percentages and Ratios

Detailed concept notes
1. Understanding percentages

A percentage expresses a quantity out of 100. The word percent means “per hundred”. It is useful for comparing quantities, describing changes, calculating marks, discounts, interest and interpreting data.

p% = p/100.

To find p% of a quantity N, multiply N by p/100.

Example: 25% of 240 = (25/100) × 240 = 60.

2. Converting between fractions, decimals and percentages
  • Fraction to percentage: multiply by 100.
  • Percentage to fraction: write it over 100 and simplify.
  • Decimal to percentage: multiply by 100.
  • Percentage to decimal: divide by 100.

For example, 3/4 = 0.75 = 75%.

Common equivalents: 1/2 = 50%, 1/4 = 25%, 1/5 = 20%, 1/8 = 12.5%, and 1/10 = 10%.

3. Percentage increase and decrease

Percentage change compares the amount of change with the original value, not the final value.

Percentage change = (Change / Original value) × 100.

Example: A quantity rises from 80 to 100.

  1. Increase = 100 − 80 = 20.
  2. Original value = 80.
  3. Percentage increase = (20/80) × 100 = 25%.

For a decrease, use the original value in the denominator in exactly the same way.

4. Successive percentage changes

When a value changes more than once, apply each change to the value after the previous change. Do not simply add the percentages unless the question specifically uses the same original base.

For two successive changes of a% and b%, the net percentage change is:

Net change = a + b + (ab/100)%.

Use a negative value for a decrease.

Example: A value increases by 10% and then decreases by 10%.

Net change = 10 − 10 + (10 × −10)/100 = −1%. The final value is 1% below the original.

5. Ratios and their meaning

A ratio compares two or more quantities measured in the same units. The ratio a:b means that for every b parts of the second quantity, there are a parts of the first quantity.

Ratios should be simplified by dividing every term by their common factor.

Example: 24:36 = 2:3 after dividing both terms by 12.

Always convert quantities to the same unit before forming a ratio.

6. Dividing a quantity in a given ratio

To divide a total amount T in the ratio a:b:

  1. Add the ratio parts: a + b.
  2. First share = T × a/(a + b).
  3. Second share = T × b/(a + b).

Worked example: Divide 80 in the ratio 3:5.

  1. Total parts = 3 + 5 = 8.
  2. One part = 80/8 = 10.
  3. Shares = 3 × 10 = 30 and 5 × 10 = 50.
7. Proportion

A proportion states that two ratios are equal. If a:b = c:d, then a/b = c/d and, when the terms are defined, ad = bc.

Example: If 2:3 = x:12, then 2/3 = x/12. Cross multiplication gives 3x = 24, so x = 8.

8. Direct and inverse proportion

Direct proportion: Two quantities increase or decrease together in the same ratio. If y is directly proportional to x, then y = kx, where k is a constant.

Inverse proportion: When one quantity increases, the other decreases so that their product remains constant. If y is inversely proportional to x, then xy = k.

Example: At a fixed speed, travel time is inversely proportional to distance? No: at fixed speed, time is directly proportional to distance. For a fixed distance, time is inversely proportional to speed.

9. Combining ratios

Suppose A:B = 2:3 and B:C = 4:5. The B terms must first be made equal.

  1. Multiply 2:3 by 4 to get A:B = 8:12.
  2. Multiply 4:5 by 3 to get B:C = 12:15.
  3. Therefore A:B:C = 8:12:15 and A:C = 8:15.
10. Applications in aptitude questions
  • Marks: Calculate a percentage of total marks or compare scores.
  • Discount: Find the reduction from a marked price.
  • Population: Apply successive growth or decline rates.
  • Mixtures: Compare quantities of ingredients using ratios.
  • Work sharing: Divide a total according to contribution ratios.
  • Data interpretation: Convert chart values into percentages and compare proportions.
11. Useful shortcuts and checks
  • 10% of a number is one-tenth of it; 5% is half of 10%.
  • 1% is one-hundredth of the number.
  • To find 15%, calculate 10% + 5%.
  • To check a divided ratio, add the shares and confirm they equal the original total.
  • For percentage change, always use the original value as the base.
  • For ratios, ensure all compared quantities use the same units.
12. Common mistakes
  • Using the new value instead of the original value when calculating percentage change.
  • Adding successive percentage changes without accounting for the changing base.
  • Comparing quantities in different units without conversion.
  • Dividing by one ratio term instead of the sum of all parts.
  • Combining ratios before making the shared term equal.
13. A tougher exam-style approach

Translate the wording into a relationship before calculating. Identify the original base for percentage questions, the total number of parts for ratio questions, and whether a relationship is direct or inverse for proportion questions. Estimate the answer first, then calculate exactly to catch arithmetic errors.

Important formulas and quick reference
  • x% of N = xN/100.
  • Percentage change = (change/original) × 100.
  • If a:b and total T, first share = aT/(a+b).
Worked example

Divide 360 in the ratio 5:7.

  1. Total parts = 12.
  2. One part = 360/12 = 30.
  3. Shares = 150 and 210.

Chapter 1: Number Systems and Binary Arithmetic

1. Positional number systems

A positional number system represents a number using digits whose values depend on their positions. The common systems in digital electronics are decimal (base 10), binary (base 2), octal (base 8) and hexadecimal (base 16).

A number in base b can be expanded as:

\(N=(a_n a_{n-1}\ldots a_0)_b=\sum_{i=0}^{n}a_i b^i\)

Each digit aᵢ must satisfy 0 ≤ aᵢ ≤ b − 1.

Number conversions

  • Binary to decimal: multiply each bit by its corresponding power of 2 and add.
  • Decimal to binary: repeatedly divide the integer part by 2 and read remainders upwards.
  • Binary to octal: group bits in sets of three from the binary point.
  • Binary to hexadecimal: group bits in sets of four.

Signed number representation

For an n-bit representation, unsigned values range from 0 to 2ⁿ − 1. In two's complement representation, signed values range from −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1.

To obtain the negative of a binary number in two's complement, invert all bits and add 1.

Binary arithmetic

Binary addition follows the same principle as decimal addition, but each column has only two digits. Important rules include 0 + 0 = 0, 0 + 1 = 1 and 1 + 1 = 10₂.

Subtraction can be performed using the two's complement of the subtracted operand.

Overflow

In signed two's complement addition, overflow occurs when two operands with the same sign produce a result with the opposite sign. A carry out of the most significant bit alone does not establish signed overflow.

Chapter 2: Boolean Algebra and Logic Gates

Boolean algebra

Boolean algebra works with two values: 0 and 1. It forms the mathematical foundation of digital circuits.

  • OR: A + B
  • AND: A · B
  • NOT: A̅
  • XOR: A ⊕ B
  • XNOR: Complement of XOR.

Important Boolean laws

  • Identity: A + 0 = A; A · 1 = A.
  • Null: A + 1 = 1; A · 0 = 0.
  • Idempotent: A + A = A; A · A = A.
  • Complement: A + A̅ = 1; A · A̅ = 0.
  • Commutative: A + B = B + A.
  • Associative: (A + B) + C = A + (B + C).
  • Distributive: A(B + C) = AB + AC.
  • De Morgan's laws: (AB)̅ = A̅ + B̅ and (A + B)̅ = A̅B̅.

Logic gates

AND produces 1 only when all inputs are 1. OR produces 1 when at least one input is 1. NOT reverses the input. NAND and NOR are universal gates because either type can be used to construct any Boolean function.

XOR produces 1 when its inputs differ. XNOR produces 1 when its inputs are equal.

Canonical forms

Sum of Products (SOP) is an OR of product terms. Product of Sums (POS) is an AND of sum terms. A minterm is 1 for exactly one input combination; a maxterm is 0 for exactly one input combination.

Worked example

Simplify: A + AB.

A + AB = A(1 + B) = A · 1 = A.

  2. State both De Morgan's laws.
  3. Why are NAND and NOR called universal gates?
  4. How many input combinations are possible for a three-input Boolean function?
Reveal answers

1. A + B. 2. (AB)̅ = A̅ + B̅ and (A + B)̅ = A̅B̅. 3. Either gate can implement all basic logic operations. 4. 2³ = 8.

Chapter 3: Combinational and Sequential Circuits

Combinational circuits

The output of a combinational circuit depends only on its present inputs. It has no memory of previous input combinations.

  • Half adder: Adds two bits. Sum = A ⊕ B; Carry = AB.
  • Full adder: Adds A, B and carry-in. Sum = A ⊕ B ⊕ Cᵢₙ.
  • Multiplexer: Selects one of several inputs using selection lines.
  • Demultiplexer: Routes one input to one of several outputs.
  • Encoder: Converts an active input into a coded output.
  • Decoder: Converts a coded input into one of several outputs.
  • Comparator: Compares two binary values.

Sequential circuits

A sequential circuit depends on current inputs and stored previous state. It contains memory elements and commonly uses a clock.

  • Latch: A level-sensitive storage element.
  • Flip-flop: A clock-controlled storage element.
  • SR flip-flop: Set-reset storage element.
  • D flip-flop: Stores the value at its D input at the active clock edge.
  • JK flip-flop: An improved SR-style flip-flop with a toggle condition.
  • T flip-flop: Toggles its state when T = 1 at the active clock edge.

Registers and counters

A register stores a group of bits. Shift registers move data left or right. Counters change their stored state in a defined sequence and may be synchronous or asynchronous.

Timing concepts

Propagation delay is the time between an input change and the corresponding output response. Setup time is the minimum time data must be stable before the active clock edge. Hold time is the minimum time data must remain stable after that edge.

Worked example

Question: A half adder receives A = 1 and B = 1. Find its outputs.

Sum = 1 ⊕ 1 = 0. Carry = 1 · 1 = 1. Therefore, the output is Sum = 0 and Carry = 1.

  4. How does a sequential circuit differ from a combinational circuit?

1. Three. 2. A flip-flop or latch. 3. Sum = 1, Carry = 1. 4. A sequential circuit also depends on stored state.

Chapter 1: Computer Structure and Instruction Execution

Basic computer organisation

A computer system contains a processor, memory and input/output components. The processor executes instructions and coordinates data movement.

  • ALU: Performs arithmetic and logical operations.
  • Control Unit: Coordinates instruction execution and control signals.
  • Registers: Small, fast storage locations inside the processor.
  • Memory: Stores instructions and data.
  • I/O interfaces: Connect external devices to the system.

Important registers

The Program Counter (PC) identifies the address of the next instruction. The Instruction Register (IR) holds the current instruction. The Memory Address Register (MAR) holds a memory address, while the Memory Data Register (MDR) holds data transferred to or from memory.

Instruction cycle

  1. Fetch: Read the instruction from memory.
  2. Decode: Determine the operation and required operands.
  3. Execute: Perform the operation.
  4. Memory access: Read or write memory if required.
  5. Write-back: Store the result in its destination.

Instruction formats and addressing

An instruction generally contains an operation code and operand information. Addressing modes describe how the operand is obtained.

  • Immediate: Operand value is part of the instruction.
  • Register: Operand is stored in a register.
  • Direct: Instruction contains the memory address.
  • Indirect: Instruction identifies a location that contains the effective address.
  • Indexed: Address is calculated using an index register and displacement.

RISC and CISC

RISC designs generally use a simpler instruction set and regular instruction formats. CISC designs may provide more complex instructions and addressing modes. Modern implementations can combine ideas from both approaches.

Worked example

Question: What is the purpose of the Program Counter?

Solution: It holds the address used to fetch the next instruction in the normal instruction sequence. Control-transfer instructions can change its value.

  1. Which unit performs arithmetic operations?
  2. Which register identifies the next instruction address?
  3. What is an immediate addressing mode?
  4. What is the purpose of instruction decoding?

1. ALU. 2. Program Counter. 3. The operand value is encoded within the instruction. 4. To identify the operation and required operands.

Chapter 2: Memory Hierarchy and Cache

Memory hierarchy

Computer memory is organised in levels to balance speed, capacity and cost. Registers are generally fastest, followed by cache, main memory and secondary storage.

  • Registers: Very small storage inside the CPU.
  • Cache: Stores frequently or recently used data and instructions.
  • RAM: Main working memory, generally volatile.
  • Secondary storage: Persistent storage such as SSDs and hard disks.

Locality of reference

Temporal locality means recently accessed data is likely to be accessed again. Spatial locality means nearby memory locations are likely to be accessed soon.

Cache mapping

  • Direct mapping: Each memory block maps to one specific cache line.
  • Fully associative: A memory block can occupy any cache line.
  • Set associative: A memory block maps to a set and can occupy any line within that set.

Cache performance

Hit ratio is the fraction of memory accesses found in cache. Miss ratio = 1 − Hit ratio.

\(\text{AMAT}=\text{Hit time}+\text{Miss rate}\times\text{Miss penalty}\)

AMAT is Average Memory Access Time. The formula assumes the usual single-level cache model.

Virtual memory

Virtual memory gives processes an address space that is translated into physical memory addresses. Paging divides virtual memory into pages and physical memory into frames. A page table stores the mapping.

A Translation Lookaside Buffer (TLB) caches recent address translations. A page fault occurs when a required page is not currently available in main memory.

Worked example

Question: Cache hit time is 2 ns, miss rate is 0.1 and miss penalty is 50 ns. Find AMAT.

AMAT = 2 + (0.1 × 50) = 7 ns.

Practice questions

  1. Which is generally faster: cache or RAM?
  2. What is temporal locality?
  3. Find the miss ratio when hit ratio is 0.92.
  4. What does a TLB store?
Reveal answers

1. Cache. 2. Recently accessed data is likely to be accessed again. 3. 0.08. 4. Recent virtual-to-physical address translations.

Chapter 3: I/O Organisation, Interrupts and Pipelining

I/O data transfer

  • Programmed I/O: CPU repeatedly checks device status and manages data transfer.
  • Interrupt-driven I/O: Device signals the CPU when attention is required.
  • DMA: Direct Memory Access allows a controller to transfer blocks between an I/O device and memory with reduced CPU involvement.

Interrupts

An interrupt temporarily changes the normal instruction flow so the processor can respond to an event. The processor saves the required state, executes an interrupt service routine and then resumes the interrupted work.

Pipelining

Pipelining divides instruction execution into stages so different instructions can be processed in overlapping stages. A common five-stage model is IF, ID, EX, MEM and WB.

Pipeline hazards

  • Structural hazard: Two operations require the same hardware resource at the same time.
  • Data hazard: An instruction depends on a result that has not yet become available.
  • Control hazard: A branch or jump changes the expected instruction sequence.

Forwarding, stalls, resource duplication and branch prediction are common ways to reduce the impact of hazards.

Performance

CPU execution time can be expressed as:

\(\text{CPU Time}=\text{Instruction Count}\times\text{CPI}\times\text{Clock Cycle Time}\)

CPI means average clock cycles per instruction. Clock cycle time is the duration of one clock cycle.

Worked example

Question: A processor executes 1,000 instructions at an average CPI of 2. If clock frequency is 1 GHz, find execution time.

Clock cycle time = 1 ns. Execution time = 1,000 × 2 × 1 ns = 2,000 ns = 2 μs.

  2. What type of hazard is caused by a branch instruction?
  3. What does CPI represent?
  4. What is the main purpose of pipelining?
Reveal answers

1. DMA. 2. Control hazard. 3. Average cycles per instruction. 4. Overlap instruction stages to improve throughput.

Chapter 1: C Programming Fundamentals and Pointers

Programming basics

A C program contains declarations, expressions, statements and functions. Execution normally begins from main(). Variables represent named storage locations and must be declared with suitable types.

  • int: integer values.
  • char: character values.
  • float and double: floating-point values.
  • void: absence of a value or type, depending on context.

Expressions and operators

Arithmetic operators include +, −, *, / and %. Relational operators compare values. Logical operators combine conditions. Operator precedence and associativity determine expression evaluation unless parentheses specify the order.

Functions and parameter passing

A function groups reusable operations. C passes arguments by value. A function can modify the caller's object indirectly when it receives a pointer to that object.

Arrays and strings

An array stores elements of the same type in contiguous memory. A C string is a character array terminated by the null character '\\0'. Array indexing begins at zero.

Pointers

A pointer stores an address. The address-of operator & obtains an object's address, while the dereference operator * accesses the object through a pointer.

Pointer arithmetic advances according to the size of the pointed-to type. Accessing memory through invalid or uninitialised pointers can cause undefined behaviour.

Storage and scope

Local variables have block scope. Global variables have file scope. Static storage duration allows an object to retain its value throughout program execution.

Chapter 2: Recursion and Algorithm Analysis

Recursion

Recursion occurs when a function calls itself directly or indirectly. A correct recursive solution needs a base case and a recursive case.

The base case stops further recursive calls. Each recursive step should move towards that base case.

Call stack

Each function call creates an activation record containing information such as local variables, parameters and return information. Recursive calls use additional stack space until they return.

Recurrence relations

A recurrence describes the running time or other quantity of a problem in terms of smaller instances.

For example, binary search satisfies \(T(n)=T(n/2)+\Theta(1)\), giving \(T(n)=\Theta(\log n)\).

Common growth rates

For large n, common growth orders are:

\(1 \lt \log n \lt n \lt n\log n \lt n^2 \lt n^3 \lt 2^n \lt n!\)

Asymptotic analysis describes growth as input size becomes large, ignoring constant factors and lower-order terms.

Worked example

Question: A recursive function reduces its input size by half and performs constant work at each call. What is its time complexity?

Recurrence: \(T(n)=T(n/2)+c\). The number of halvings is approximately log₂n. Therefore, the complexity is Θ(log n).

Chapter 3: Arrays, Linked Lists, Stacks and Queues

Arrays

Arrays store elements in contiguous memory. Random access using an index takes O(1) time. Inserting or deleting in the middle generally takes O(n) because elements may need to be shifted.

Linked lists

A linked list contains nodes, each storing data and one or more links. A singly linked list points to the next node. A doubly linked list stores both previous and next links.

Searching takes O(n). Insertion or deletion can take O(1) when the relevant node or link is already known.

Stacks

A stack follows Last In, First Out (LIFO). Push inserts an element, pop removes the top element and peek reads the top without removing it. These operations are generally O(1).

Applications include function calls, expression evaluation, parentheses matching and depth-first search.

Queues

A queue follows First In, First Out (FIFO). Enqueue inserts at the rear and dequeue removes from the front. Circular queues reuse available array positions.

Priority queues remove elements according to priority rather than simple insertion order.

Worked example

Question: A stack receives push(4), push(7), push(9), followed by pop(). What is on top?

Solution: The most recently inserted element 9 is removed. The new top is 7.

Chapter 4: Trees, Binary Search Trees and Heaps

Tree terminology

A tree is a hierarchical data structure. A node with no parent is the root. A leaf has no children. The depth of a node is the number of edges from the root, while height measures the longest downward path to a leaf.

Binary trees

A binary tree has at most two children per node. A full binary tree has nodes with either zero or two children. A complete binary tree has all levels full except possibly the last, which is filled from left to right.

Tree traversals

  • Preorder: Root, Left, Right.
  • Inorder: Left, Root, Right.
  • Postorder: Left, Right, Root.
  • Level order: Visit nodes level by level.

Binary Search Tree

In a standard BST, keys in the left subtree are smaller than the node key and keys in the right subtree are larger, subject to the duplicate-key convention used. Inorder traversal produces sorted keys.

A BST operation takes O(h), where h is tree height. A balanced tree has logarithmic height, while a skewed tree can have height O(n).

Heaps

A binary heap is a complete binary tree satisfying the heap-order property. In a max-heap, each parent is at least as large as its children. In a min-heap, each parent is at most as large as its children.

Heap insertion and deletion take O(log n). Reading the root takes O(1). Building a heap bottom-up takes O(n).

Worked example

Question: Find the inorder traversal of a tree with root 5, left child 3 and right child 8.

Solution: Left, Root, Right gives 3, 5, 8.

Chapter 5: Graphs and Graph Representations

Graph fundamentals

A graph is represented as G = (V, E), where V is the set of vertices and E is the set of edges. Graphs can be directed or undirected, weighted or unweighted.

The degree of a vertex in an undirected graph is the number of incident edges. In a directed graph, indegree counts incoming edges and outdegree counts outgoing edges.

Representations

  • Adjacency matrix: A V × V matrix representing connections. It uses O(V²) space.
  • Adjacency list: Stores the neighbours of each vertex. Space is O(V + E).

Graph traversal

Breadth-First Search (BFS) explores vertices level by level using a queue. Depth-First Search (DFS) explores as far as possible before backtracking, using recursion or an explicit stack.

With adjacency lists, BFS and DFS run in O(V + E) time.

Applications

Graphs model road networks, social networks, communication systems, dependencies, scheduling and state transitions.

Chapter 1: Asymptotic Analysis and Complexity

Why analyse algorithms?

Algorithm analysis estimates resource requirements as input size increases. Time complexity estimates operation growth, while space complexity estimates additional memory requirements.

Asymptotic notation

  • Big O: Asymptotic upper bound.
  • Big Ω: Asymptotic lower bound.
  • Big Θ: Asymptotically tight bound.
  • Little o: Strict asymptotic upper bound.
  • Little ω: Strict asymptotic lower bound.

Common complexity classes

Constant O(1), logarithmic O(log n), linear O(n), linearithmic O(n log n), quadratic O(n²), cubic O(n³) and exponential O(2ⁿ) are common growth classes.

Best, average and worst cases

Best case is the minimum resource use over inputs of a given size. Worst case is the maximum. Average case is the expected resource use under a specified input distribution.

Amortised analysis

Amortised analysis estimates average cost per operation over a sequence of operations, even when individual operations have occasional high costs.

Worked example

Question: A loop runs n times and performs constant work each time. Find its time complexity.

Solution: Total work is c × n for constant c, so time complexity is Θ(n).

Chapter 2: Searching and Sorting Algorithms

Linear search

Linear search checks elements one by one until the target is found or the collection ends. Worst-case time is O(n), and it does not require sorted input.

Binary search

Binary search repeatedly halves the search interval. It requires sorted data and takes O(log n) time. Its iterative implementation can use O(1) auxiliary space.

Sorting algorithms

  • Bubble sort: Repeatedly swaps adjacent out-of-order elements. Average and worst-case time are O(n²).
  • Selection sort: Repeatedly selects the smallest remaining element. Time is O(n²).
  • Insertion sort: Inserts each element into its correct position in the sorted prefix. Worst-case time is O(n²).
  • Merge sort: Divides, sorts and merges subarrays. Time is O(n log n); standard array implementation needs O(n) auxiliary space.
  • Quick sort: Partitions around a pivot. Average time is O(n log n), worst-case time is O(n²).
  • Heap sort: Uses a binary heap. Time is O(n log n) and it can sort in-place.
  • Counting sort: Uses frequency counts for keys in a suitable bounded integer range.

Stability and in-place sorting

A stable sorting algorithm preserves the relative order of equal-key elements. An in-place algorithm uses limited additional storage beyond the input, according to the convention being used.

Worked example

Question: How many comparisons are needed at most for binary search on 16 sorted elements?

Solution: Each comparison approximately halves the search interval. Since log₂16 = 4, at most 5 comparisons may be needed depending on the search implementation and counting convention. For the standard iterative process, a target can be found within 5 comparisons in the worst case for 16 elements.

Chapter 3: Divide and Conquer, Greedy Algorithms and Dynamic Programming

Divide and conquer

This approach divides a problem into smaller subproblems, solves them recursively and combines their results. Merge sort and binary search are standard examples.

A common recurrence is \(T(n)=aT(n/b)+f(n)\). The Master Theorem can help solve recurrences of this form under its stated conditions.

Greedy algorithms

A greedy algorithm makes a locally optimal choice at each step. It produces a globally optimal answer only when the problem has the required greedy-choice property and optimal substructure.

Examples include activity selection, fractional knapsack and Kruskal's and Prim's minimum spanning tree algorithms.

Dynamic programming

Dynamic programming solves problems with overlapping subproblems and optimal substructure by storing previously computed results.

  • Memoisation: Top-down recursion with stored results.
  • Tabulation: Bottom-up computation using a table.

Important distinctions

Fractional knapsack can be solved optimally using a greedy strategy based on value-to-weight ratio. The standard 0/1 knapsack problem requires a different treatment; dynamic programming is a common exact approach.

Shortest paths

A topological ordering is a linear ordering of vertices in a directed acyclic graph (DAG) such that every directed edge goes from an earlier vertex to a later vertex.

Chapter 1: Finite Automata and Regular Languages

Formal languages

An alphabet Σ is a finite non-empty set of symbols. A string is a finite sequence of symbols from Σ. A language is a set of strings over an alphabet.

Deterministic finite automaton

A DFA is represented by (Q, Σ, δ, q₀, F), where Q is the set of states, Σ is the alphabet, δ is the transition function, q₀ is the start state and F is the set of accepting states.

For each state and input symbol, a DFA has exactly one defined next state.

Non-deterministic finite automaton

An NFA may have multiple possible transitions for a state and symbol, or no transition. An ε-NFA can also make transitions without consuming an input symbol. DFAs and NFAs recognise exactly the regular languages.

Regular expressions

Regular expressions describe regular languages using operations such as union, concatenation and Kleene star. The expression a* represents zero or more repetitions of a.

Closure properties

Regular languages are closed under union, intersection, complement, concatenation, Kleene star and reversal.

Worked example

Question: What language is represented by (0 + 1)*?

Solution: It represents all finite binary strings, including the empty string.

Chapter 2: Context-Free Grammars and Pushdown Automata

Context-free grammar

A context-free grammar is represented by (V, Σ, P, S), where V is the set of variables, Σ is the terminal alphabet, P is the production set and S is the start variable.

Each production has one variable on its left-hand side. A grammar generates strings by repeatedly applying productions.

Derivations and parse trees

A derivation shows the sequence of production applications. A parse tree shows the hierarchical structure of a derivation. A grammar is ambiguous if at least one string has more than one distinct parse tree or leftmost derivation.

Pushdown automaton

A PDA is a finite-state machine equipped with a stack. The stack provides memory that allows it to recognise languages such as balanced parentheses.

Non-deterministic PDAs recognise exactly the context-free languages.

Context-free language properties

Context-free languages are closed under union, concatenation and Kleene star. They are not closed under general intersection or complement. However, intersection with a regular language is context-free.

Chapter 3: Turing Machines, Decidability and Complexity

Turing machine

A Turing machine is an abstract computational model with a finite control, an unbounded tape and a read/write head. It reads symbols, writes symbols, changes state and moves its head according to a transition function.

Decidability

A language is decidable if some Turing machine halts on every input and correctly accepts or rejects it. A language is recognisable if a machine accepts every string in the language, but may not halt on strings outside it.

Undecidable problems

The Halting Problem asks whether an arbitrary program or machine will eventually halt on a given input. It is undecidable in the general case.

Complexity classes

  • P: Decision problems solvable in polynomial time by a deterministic machine.
  • NP: Decision problems whose proposed solutions can be verified in polynomial time.
  • NP-hard: Problems at least as hard as every problem in NP under the relevant polynomial-time reductions.
  • NP-complete: Problems that are both in NP and NP-hard.

Reductions

A reduction transforms instances of one problem into instances of another while preserving the answer. Reductions are used to compare problem difficulty and establish NP-hardness or NP-completeness.

Worked example

Question: Is every problem in P also in NP?

Solution: Yes. A deterministic polynomial-time algorithm can also be used as a polynomial-time verification procedure.

Practice questions

  1. What does a decider do for every input?
  2. Is the general Halting Problem decidable?
  3. What two properties define NP-complete problems?

Chapter 1: Compiler Structure and Lexical Analysis

What is a compiler?

A compiler translates a source program into another representation, commonly machine code or an intermediate representation. It detects errors and performs transformations while preserving program meaning.

Major compiler phases

  1. Lexical analysis.
  2. Syntax analysis.
  3. Semantic analysis.
  4. Intermediate code generation.
  5. Code optimisation.
  6. Target code generation.

Lexical analysis

The lexical analyser reads characters and groups them into tokens. A token may represent an identifier, keyword, operator, constant or punctuation symbol.

A lexeme is the actual character sequence in the source code. A pattern describes the form of lexemes belonging to a token class.

Regular expressions and finite automata

Token patterns are commonly described using regular expressions and implemented using finite automata. The lexical analyser may also maintain a symbol table for identifiers and related information.

Lexical errors

Invalid characters, malformed numeric literals and incomplete tokens may cause lexical errors. Error handling attempts to identify and report the problem clearly.

Chapter 2: Syntax Analysis and Parsing

Syntax analysis

The parser checks whether the token sequence follows the grammar of the programming language. It constructs a parse tree or an abstract syntax tree.

Top-down parsing

Top-down parsing starts from the grammar's start symbol and attempts to derive the input. Recursive-descent and predictive LL(1) parsing are common examples.

FIRST and FOLLOW

FIRST(X) contains terminals that can begin strings derived from X. FOLLOW(A) contains terminals that can appear immediately after nonterminal A in a sentential form.

These sets help construct predictive parsing tables.

Left recursion and left factoring

A grammar is left recursive if a nonterminal can derive a string beginning with itself. Direct left recursion can prevent ordinary top-down predictive parsing. Left factoring extracts common prefixes to make parsing decisions easier.

Bottom-up parsing

Bottom-up parsing constructs the parse from input symbols towards the start symbol. LR parsing is a powerful bottom-up technique.

  • LR(0): Uses zero-symbol lookahead.
  • SLR(1): Uses FOLLOW sets for reductions.
  • Canonical LR(1): Uses one-symbol lookahead in items.
  • LALR(1): Combines compatible LR(1) states to reduce table size.

Worked example

Question: What is the main difference between top-down and bottom-up parsing?

Solution: Top-down parsing starts from the start symbol and derives the input. Bottom-up parsing starts with input symbols and reduces them towards the start symbol.

Chapter 3: Semantic Analysis, Intermediate Code and Optimisation

Semantic analysis

Semantic analysis checks whether a syntactically valid program follows language rules. It includes type checking, scope checking, declaration checking and compatibility of operations.

Symbol tables

A symbol table stores information about identifiers, such as name, type, scope, storage location and other attributes needed by the compiler.

Intermediate representation

An intermediate representation (IR) separates source-language analysis from target-machine code generation. Three-address code is a common representation.

Example: For x = a + b * c, an intermediate sequence may be t1 = b * c; t2 = a + t1; x = t2.

Syntax-directed translation

Syntax-directed definitions associate attributes and semantic rules with grammar productions. Synthesised attributes are computed from child nodes, while inherited attributes are obtained from parent or sibling context.

Code optimisation

  • Constant folding: Evaluate constant expressions during compilation.
  • Common subexpression elimination: Avoid repeated computation of an unchanged expression.
  • Dead-code elimination: Remove computations that cannot affect observable program behaviour.
  • Copy propagation: Replace uses of a copied variable with the original value where valid.
  • Loop optimisation: Apply transformations that improve loop execution without changing program meaning.

Code generation

The code generator maps intermediate operations to target instructions. Register allocation assigns values to available processor registers, sometimes using spilling when registers are insufficient.

Chapter 1: Processes, Threads and CPU Scheduling

Operating system basics

An operating system manages hardware resources and provides services to programs. Important responsibilities include process management, memory management, file management and device management.

Processes

A process is a program in execution. It has an address space and execution state. A process control block stores information such as process state, program counter, registers and scheduling information.

Common process states include new, ready, running, waiting and terminated.

Threads

A thread is an execution unit within a process. Threads in the same process generally share code, data and open resources, but each thread has its own execution state and stack.

CPU scheduling

  • FCFS: First Come, First Served.
  • SJF: Shortest Job First.
  • SRTF: Shortest Remaining Time First.
  • Priority: Selects based on priority.
  • Round Robin: Gives processes time slices in cyclic order.

Scheduling calculations

Turnaround time = Completion time − Arrival time.

Waiting time = Turnaround time − CPU burst time, for the usual single-burst model.

Response time = First CPU start time − Arrival time.

Chapter 2: Process Synchronisation and Deadlocks

Critical section

A critical section is a part of a program that accesses shared data or resources. Concurrent execution can cause race conditions if access is not properly coordinated.

A correct critical-section solution aims to satisfy mutual exclusion, progress and bounded waiting.

Synchronisation mechanisms

  • Mutex: Provides exclusive access to a protected resource.
  • Semaphore: An integer-based synchronisation mechanism controlled through atomic operations such as wait and signal.
  • Monitor: A high-level synchronisation construct that controls access to shared data.

Deadlocks

A deadlock is a state in which a set of processes waits indefinitely for resources held by one another.

Four necessary conditions are mutual exclusion, hold and wait, no preemption and circular wait.

Deadlock handling

  • Prevention: Ensure at least one necessary condition cannot hold.
  • Avoidance: Grant requests only when the system remains in a safe state.
  • Detection: Identify deadlocks after they occur.
  • Recovery: Take actions to break the deadlock.

Banker's algorithm

Banker's algorithm checks whether granting a resource request leaves the system in a safe state. A safe sequence is an ordering in which each process can finish with currently available resources plus resources released by earlier completed processes.

Worked example

Chapter 3: Memory Management and Virtual Memory

Memory management

The operating system manages allocation and protection of main memory. Address binding may occur at compile time, load time or execution time.

Contiguous allocation

Memory may be divided into partitions. Variable-sized allocation can create external fragmentation, while fixed-sized allocation can cause internal fragmentation.

Paging

Paging divides virtual memory into fixed-size pages and physical memory into frames of the same size. A page table maps virtual pages to physical frames.

For page size S and logical address A, page number = floor(A/S), and offset = A mod S.

Segmentation

Segmentation divides a program into logical variable-sized units such as code, data and stack. A logical address consists of a segment identifier and offset.

Virtual memory

Virtual memory allows processes to use an address space larger than the currently allocated physical memory. Demand paging loads pages when needed.

Page replacement

  • FIFO: Replaces the oldest loaded page.
  • LRU: Replaces the page least recently used.
  • Optimal: Replaces the page whose next use is farthest in the future; useful as a theoretical benchmark.

A page fault occurs when a required virtual page is not present in physical memory.

Worked example

Page number = floor(2500/1024) = 2. Offset = 2500 − 2048 = 452 bytes.

File system

A file system organises persistent data into files and directories. It maintains metadata such as file size, permissions, timestamps and storage locations.

File permissions and access-control mechanisms determine which users or processes can read, write or execute files. The operating system also manages device drivers and I/O buffering.

Database concepts

A database is an organised collection of related data. A DBMS provides facilities to define, store, retrieve, update and control access to that data.

Relational model

A relation is represented as a table. A tuple is a row, an attribute is a column and a domain defines the permitted values of an attribute.

Keys

  • Candidate key: Minimal superkey.

  • Foreign key: Attribute set referencing a candidate key in another or the same relation.
  • Composite key: Key consisting of more than one attribute.

Integrity constraints

Entity integrity requires primary-key values to be unique and non-null. Referential integrity ensures that a foreign-key value refers to an existing referenced key value or is null where permitted.

Relational algebra

  • Cartesian product (×): Combines every tuple pair.
  • Join (⋈): Combines related tuples.
  • Rename (ρ): Renames a relation or its attributes.

Chapter 3: Functional Dependencies and Normalisation

Functional dependencies

A functional dependency X → Y means that if two tuples agree on attributes X, they must also agree on attributes Y.

For example, if every student ID identifies exactly one student name, then StudentID → StudentName.

Attribute closure

The closure X⁺ is the set of all attributes functionally determined by X using the given dependencies. It helps identify candidate keys and test whether a dependency follows from a set of dependencies.

Normal forms

  • 1NF: Attributes contain atomic values under the chosen relational model.
  • 2NF: In 1NF, with no non-prime attribute partially dependent on any candidate key.
  • 3NF: For every non-trivial X → A, X is a superkey or A is prime.
  • BCNF: For every non-trivial functional dependency X → Y, X is a superkey.

Why normalise?

Normalisation reduces undesirable redundancy and prevents insertion, update and deletion anomalies. Decomposition should be assessed for losslessness and dependency preservation.

Transactions

Transactions can wait for locks held by one another. A wait-for graph represents such dependencies; a cycle indicates deadlock under the standard locking model.

Write-ahead logging records necessary log information before corresponding data pages are written. Recovery uses logs to redo or undo operations as required by the recovery protocol.

Chapter 1: Probability Fundamentals and Conditional Probability

Basic terminology

A random experiment is a process whose outcome cannot be predicted with certainty. The sample space Ω contains all possible outcomes. An event is a subset of the sample space.

For equally likely outcomes, the probability of an event A is:

\(P(A)=\frac{\text{Number of favourable outcomes}}{\text{Total number of outcomes}}\)

Probability laws

  • 0 ≤ P(A) ≤ 1.
  • P(Ω) = 1 and P(∅) = 0.
  • Complement: P(Aᶜ) = 1 − P(A).
  • Addition rule: P(A ∪ B) = P(A) + P(B) − P(A ∩ B).

Conditional probability

Conditional probability measures the probability of A when B is already known to have occurred.

\(P(A\mid B)=\frac{P(A\cap B)}{P(B)},\quad P(B)>0\)

Independence

Events A and B are independent if P(A ∩ B) = P(A)P(B). Equivalently, when P(B) is positive, P(A | B) = P(A).

Mutually exclusive events cannot occur together, while independent events do not change each other's probabilities. These concepts are not interchangeable.

Bayes' theorem

\(P(A_i\mid B)=\frac{P(B\mid A_i)P(A_i)}{\sum_j P(B\mid A_j)P(A_j)}\)

Bayes' theorem updates prior probabilities using observed evidence. The denominator is the total probability of the evidence.

Worked example

Question: A fair die is rolled. Given that the result is even, what is the probability that it is greater than 3?

Even outcomes are {2, 4, 6}. Outcomes that are both even and greater than 3 are {4, 6}. Therefore, the probability is 2/3.

  2. If A and B are independent, express P(A ∩ B).
  3. What is the addition rule for two events?

Chapter 2: Random Variables, Expectation and Distributions

Random variables

A random variable assigns a numerical value to each outcome of a random experiment. A discrete random variable has countable possible values; a continuous random variable can take values over intervals.

Probability distributions

A probability mass function (PMF) describes a discrete random variable. A probability density function (PDF) describes a continuous random variable. A cumulative distribution function (CDF) is defined as F(x) = P(X ≤ x).

Expectation and variance

For a discrete random variable:

\(E[X]=\sum_x xP(X=x)\)

For a continuous random variable with density f(x):

\(E[X]=\int_{-\infty}^{\infty}xf(x)\,dx\)

Variance measures spread around the mean:

\(\operatorname{Var}(X)=E[(X-\mu)^2]=E[X^2]-(E[X])^2\)

Important distributions

  • Bernoulli: One trial with success probability p. Mean = p; variance = p(1 − p).
  • Binomial: Number of successes in n independent Bernoulli trials. Mean = np; variance = np(1 − p).
  • Geometric: Number of trials until the first success under the usual trial-count convention. Mean = 1/p.
  • Poisson: Models counts with rate λ under its assumptions. Mean = λ; variance = λ.
  • Uniform continuous: For X uniformly distributed on [a, b], mean = (a + b)/2 and variance = (b − a)²/12.
  • Normal: A symmetric bell-shaped distribution with mean μ and variance σ².
  • Exponential: Models non-negative waiting times with rate λ. Mean = 1/λ.

Joint distributions

A joint distribution describes two or more random variables together. Marginal distributions are obtained by summing or integrating over the other variables. Covariance measures how two variables vary together.

\(\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]\)

Worked example

Question: A Bernoulli random variable has success probability 0.7. Find its mean and variance.

Mean = 0.7. Variance = 0.7 × 0.3 = 0.21.

Chapter 3: Sampling, Estimation and Hypothesis Testing

Population and sample

A population is the complete group under study. A sample is a subset selected from that population. A statistic is calculated from sample data, while a parameter describes the population.

Sampling concepts

Random sampling gives units a defined chance of selection. Sampling distributions describe how a statistic varies across repeated samples. The standard error measures the variability of an estimator or statistic.

Central Limit Theorem

Under suitable independence and finite-variance conditions, the distribution of a suitably standardised sample mean approaches a normal distribution as sample size increases.

For independent observations with mean μ and variance σ²:

\(E[\bar X]=\mu,\qquad \operatorname{Var}(\bar X)=\frac{\sigma^2}{n}\)

Point and interval estimation

A point estimator gives one estimated value of a population parameter. A confidence interval gives a range produced by a procedure with a specified long-run coverage level.

Hypothesis testing

The null hypothesis H₀ represents a reference claim. The alternative hypothesis H₁ represents a competing claim. A test statistic is calculated from the sample and compared with a decision rule.

  • Significance level α: Chosen probability of a Type I error under the null hypothesis.
  • Type I error: Rejecting a true null hypothesis.
  • Type II error: Failing to reject a false null hypothesis.
  • Power: Probability of rejecting the null when a specified alternative is true.
  • p-value: Probability, under the null model, of a test statistic at least as extreme as the observed one.

Worked example

Question: A sample has n = 100 and population standard deviation σ = 20. Find the standard error of the sample mean.

Standard error = σ/√n = 20/10 = 2.

Chapter 1: Matrices, Determinants and Linear Systems

Matrix fundamentals

A matrix is a rectangular arrangement of elements. Its order is the number of rows multiplied by the number of columns. A square matrix has equal row and column counts.

Important types include zero, identity, diagonal, triangular, symmetric and skew-symmetric matrices.

Matrix operations

Matrix addition requires equal dimensions. Matrix multiplication is defined when the number of columns of the first matrix equals the number of rows of the second.

In general, matrix multiplication is not commutative: AB need not equal BA.

Determinants and inverse

The determinant is defined for square matrices. A square matrix is invertible exactly when its determinant is non-zero.

For a 2 × 2 matrix:

\(A=\begin{bmatrix}a&b\\c&d\end{bmatrix},\quad \det(A)=ad-bc\)

When ad − bc is non-zero:

\(A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\)

Systems of linear equations

A system can be written as Ax = b. The rank of a matrix is the maximum number of linearly independent rows or columns.

The system is consistent when rank(A) = rank([A | b]). If this common rank equals the number of unknowns, the solution is unique. If it is smaller, there are infinitely many solutions.

Worked example

Question: Find the determinant of [[2, 1], [3, 4]].

det(A) = 2 × 4 − 1 × 3 = 5.

Chapter 2: Vector Spaces, Basis and Orthogonality

Vectors and vector spaces

A vector is an ordered collection of components. A vector space is a set with vector addition and scalar multiplication satisfying the vector-space axioms.

Linear combinations and span

A linear combination of vectors v₁, …, vₙ has the form c₁v₁ + … + cₙvₙ. The span is the set of all linear combinations of a given collection.

Linear independence

Vectors are linearly independent if the equation c₁v₁ + … + cₙvₙ = 0 has only the trivial solution in which all coefficients are zero.

Basis and dimension

A basis is a linearly independent set that spans the vector space. The number of vectors in a basis is the dimension of the space.

Inner product and norms

For real vectors, the standard inner product is:

\(\langle x,y\rangle=x^Ty=\sum_i x_i y_i\)

The Euclidean norm is:

\(\|x\|_2=\sqrt{\sum_i x_i^2}\)

Two vectors are orthogonal when their inner product is zero.

Orthogonal projection

The projection of x onto a non-zero vector u is:

\(\operatorname{proj}_u(x)=\frac{x^Tu}{u^Tu}u\)

1 × 3 + 2 × 4 = 11.

Chapter 3: Eigenvalues, Eigenvectors and Matrix Decompositions

Eigenvalues and eigenvectors

A non-zero vector v is an eigenvector of A with eigenvalue λ if:

\(Av=\lambda v\)

Eigenvalues satisfy the characteristic equation:

\(\det(A-\lambda I)=0\)

Important properties

  • The sum of eigenvalues, counted with algebraic multiplicity, equals the trace.
  • The product of eigenvalues, counted with algebraic multiplicity, equals the determinant.
  • For a triangular matrix, diagonal entries are eigenvalues.
  • Real symmetric matrices have real eigenvalues and can be orthogonally diagonalised.

Diagonalisation

A matrix is diagonalisable if it has a basis of eigenvectors. When enough linearly independent eigenvectors exist, A = PDP⁻¹, where D is diagonal and P contains eigenvectors as columns.

Singular Value Decomposition

Any real matrix A can be expressed as:

\(A=U\Sigma V^T\)

U and V are orthogonal matrices, and Σ contains non-negative singular values. SVD is useful in dimensionality reduction, compression and least-squares problems.

Principal Component Analysis

PCA identifies directions of maximum variance in data. In the standard covariance-based approach, eigenvectors of the covariance matrix provide principal directions, while their eigenvalues describe variance along those directions.

Chapter 1: Limits, Continuity and Differentiation

Limits

A limit describes the value a function approaches as its input approaches a specified point. Limits help define continuity and derivatives.

Continuity

A function f is continuous at x = a when f(a) is defined, the limit as x approaches a exists, and that limit equals f(a).

Derivatives

The derivative represents the instantaneous rate of change of a function.

\(f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}\)

Important differentiation rules

  • Power rule: \(\frac{d}{dx}x^n=nx^{n-1}\).
  • Product rule: \((uv)'=u'v+uv'\).
  • Quotient rule: \((u/v)'=(u'v-uv')/v^2\), where v is non-zero.
  • Chain rule: \(\frac{d}{dx}f(g(x))=f'(g(x))g'(x)\).

Common derivatives

\(\frac{d}{dx}\sin x=\cos x,\quad \frac{d}{dx}\cos x=-\sin x\)

\(\frac{d}{dx}e^x=e^x,\quad \frac{d}{dx}\ln x=\frac{1}{x}\quad(x>0)\)

f'(x) = 6x + 4.

Chapter 2: Partial Derivatives and Multivariable Calculus

Functions of several variables

A multivariable function depends on two or more inputs, such as f(x, y). A partial derivative measures change with respect to one variable while holding the others constant.

\(\frac{\partial f}{\partial x}\quad\text{and}\quad\frac{\partial f}{\partial y}\)

Gradient

The gradient collects first-order partial derivatives:

\(\nabla f=\begin{bmatrix}\frac{\partial f}{\partial x_1}&\cdots&\frac{\partial f}{\partial x_n}\end{bmatrix}^T\)

It points in the direction of steepest local increase for a differentiable function under the standard Euclidean geometry.

Directional derivatives

For a unit direction vector u, the directional derivative is:

\(D_u f=\nabla f\cdot u\)

Hessian matrix

The Hessian contains second-order partial derivatives. It helps classify stationary points and assess local curvature.

Chain rule for multiple variables

If z = f(x, y), and x and y depend on t, then:

\(\frac{dz}{dt}=\frac{\partial f}{\partial x}\frac{dx}{dt}+\frac{\partial f}{\partial y}\frac{dy}{dt}\)

Worked example

Question: For f(x, y) = x² + 3xy + y², find the gradient.

\(\frac{\partial f}{\partial x}=2x+3y,\quad \frac{\partial f}{\partial y}=3x+2y\)

Therefore, \(\nabla f=(2x+3y,\;3x+2y)^T\).

Chapter 3: Integration and Optimisation

Integration

Integration is used to find antiderivatives and accumulated quantities. For a continuous function, a definite integral represents signed area over an interval.

\(\int x^n\,dx=\frac{x^{n+1}}{n+1}+C,\quad n\ne -1\)

\(\int_a^b f(x)\,dx=F(b)-F(a)\), where F is an antiderivative of f.

Integration techniques

  • Substitution: Replaces an inner expression with a new variable.
  • Integration by parts: \(\int u\,dv=uv-\int v\,du\).
  • Partial fractions: Decomposes suitable rational functions into simpler terms.

Unconstrained optimisation

A stationary point satisfies ∇f(x) = 0 when f is differentiable and the point is an interior point. In one variable, a positive second derivative at a stationary point indicates a strict local minimum; a negative second derivative indicates a strict local maximum.

Multivariable second-order conditions

The Hessian can help classify a stationary point. Positive definiteness indicates a strict local minimum, while negative definiteness indicates a strict local maximum. Indefinite Hessian indicates a saddle point.

Gradient descent

Gradient descent updates parameters in the direction opposite the gradient:

\(\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t)\)

η is the learning rate, J is the objective function and θ represents parameters.

Constrained optimisation

Constraints restrict the feasible solutions. Lagrange multipliers can be used for equality-constrained problems by constructing a Lagrangian from the objective and constraints.

Worked example

Question: Find the minimum of f(x) = x² − 6x + 10.

f'(x) = 2x − 6 = 0 gives x = 3. Since f''(x) = 2 is positive, the minimum occurs at x = 3. The minimum value is 1.

Chapter 3: Model Evaluation and Validation

Confusion matrix

For binary classification, a confusion matrix contains true positives (TP), true negatives (TN), false positives (FP) and false negatives (FN).

\(\text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}\)

\(\text{Precision}=\frac{TP}{TP+FP}\)

\(\text{Recall}=\frac{TP}{TP+FN}\)

\(F_1=2\frac{\text{Precision}\times\text{Recall}}{\text{Precision}+\text{Recall}}\)

Mean Absolute Error averages absolute prediction errors. Mean Squared Error averages squared errors. Root Mean Squared Error is the square root of MSE. R² compares model performance with a baseline based on the target mean under the usual definition.

The ROC curve plots true positive rate against false positive rate across thresholds. AUC summarises ranking performance across thresholds.

Cross-validation

In k-fold cross-validation, data is divided into k folds. Each fold is used for validation once while the others are used for training. The results are combined to estimate model performance.

Class imbalance

When one class is much more common than another, accuracy may be misleading. Precision, recall, F1-score, balanced accuracy and suitable threshold analysis can provide more useful information.

Chapter 4: Unsupervised Learning and Clustering

Unsupervised learning

Unsupervised learning discovers patterns in data without using target labels. Common tasks include clustering, dimensionality reduction and density estimation.

k-Means clustering

k-Means partitions observations into k clusters by assigning each point to a nearest centroid and updating centroids to minimise within-cluster squared distances.

  1. Choose k initial centroids.
  2. Assign each point to its nearest centroid.
  3. Recompute each centroid as the mean of its assigned points.
  4. Repeat until assignments or centroids stabilise.

Hierarchical clustering

Agglomerative clustering begins with individual points and repeatedly merges clusters. Divisive clustering begins with one cluster and repeatedly splits it. Linkage criteria determine how cluster distances are measured.

Dimensionality reduction

PCA transforms data into orthogonal directions ordered by explained variance. It can reduce the number of features while retaining much of the variation in the data.

Clustering evaluation

The silhouette coefficient compares how close a point is to its own cluster with how close it is to other clusters. It is commonly used to assess cluster separation and cohesion.

Worked example

Question: What does k represent in k-Means?

Solution: The number of clusters requested.

Chapter 1: Intelligent Agents and Problem Formulation

Artificial intelligence

Artificial Intelligence studies systems that perform tasks involving reasoning, learning, perception, planning or decision-making.

Intelligent agents

An agent perceives its environment through sensors and acts through actuators. A rational agent selects actions that maximise expected performance according to its available information and performance measure.

PEAS framework

PEAS describes an agent's task environment through Performance measure, Environment, Actuators and Sensors.

Environment properties

Environments may be fully or partially observable, deterministic or stochastic, episodic or sequential, static or dynamic, discrete or continuous, and single-agent or multi-agent.

Problem formulation

A search problem typically defines an initial state, available actions, a transition model, a goal test and a path-cost function.

Solution: State: current location. Action: travel along an available road. Goal: reach the destination.

Chapter 2: Uninformed and Informed Search

Uninformed search

  • Breadth-First Search: Expands the shallowest nodes first. It is complete under finite branching and finds minimum-depth solutions when step costs are equal.
  • Depth-First Search: Expands a deepest node first. It uses relatively little memory but may fail to find a solution in infinite-depth spaces.
  • Uniform-Cost Search: Expands the node with the lowest path cost. It is optimal under suitable non-negative cost assumptions.
  • Iterative Deepening: Repeats depth-limited search with increasing limits.

Heuristic search

A heuristic h(n) estimates the remaining cost from node n to a goal. Greedy best-first search prioritises the estimated remaining cost.

A* search

A* evaluates nodes using:

\(f(n)=g(n)+h(n)\)

g(n) is the path cost so far and h(n) is the estimated remaining cost. An admissible heuristic never overestimates the true minimum remaining cost.

Heuristic properties

A consistent heuristic satisfies h(n) ≤ c(n, n') + h(n') for every transition from n to n'. Consistency implies admissibility when the goal heuristic is zero.

Worked example

Question: A search node has path cost g(n) = 8 and heuristic estimate h(n) = 5. Find its A* evaluation.

f(n) = 8 + 5 = 13.

Practice questions

  1. Which search strategy expands the shallowest node first?
  2. What does h(n) estimate?
  3. What is the A* evaluation function?
  4. What is an admissible heuristic?
Reveal answers

1. BFS. 2. Remaining cost to a goal. 3. g(n) + h(n). 4. A heuristic that never overestimates the true minimum remaining cost.

Chapter 3: Game Playing, Logic and Knowledge Representation

Adversarial search

Adversarial search models decision-making where agents have opposing objectives, as in two-player games.

Minimax

Minimax selects a move assuming both players act optimally. MAX attempts to maximise the utility, while MIN attempts to minimise it.

Alpha-beta pruning

Alpha-beta pruning avoids exploring branches that cannot affect the final minimax decision. It preserves the result of minimax while potentially reducing the number of nodes explored.

Propositional logic

Propositions are statements that are either true or false. Logical operators include NOT, AND, OR, implication and biconditional.

First-order logic

First-order logic extends propositional logic with predicates, variables, functions and quantifiers. The universal quantifier means “for all”, while the existential quantifier means “there exists”.

Knowledge representation

Knowledge bases store facts and rules. Inference derives new conclusions from stored information. Ontologies describe concepts, properties and relationships within a domain.

Worked example

Question: What is the purpose of alpha-beta pruning?

Solution: It reduces unnecessary search while retaining the same minimax decision.

  1. Which player does MAX represent in minimax?
  2. Does alpha-beta pruning change the minimax result?
  3. Which quantifier means “there exists”?
  4. What is a knowledge base?
Reveal answers

1. The player maximising utility. 2. No. 3. Existential quantifier. 4. A collection of facts and rules used for reasoning.

Chapter 4: Probabilistic Reasoning and Decision-Making

Reasoning under uncertainty

AI systems often operate with incomplete or uncertain information. Probability provides a mathematical framework for representing uncertainty and updating beliefs.

Bayesian networks

A Bayesian network is a directed acyclic graph in which nodes represent random variables and edges represent conditional dependencies. Each node has a conditional probability distribution given its parents.

The joint distribution factorises as:

\(P(X_1,\ldots,X_n)=\prod_{i=1}^{n}P(X_i\mid Parents(X_i))\)

Conditional independence

Conditional independence means two variables become independent when a specified third variable or set of variables is known. It is a central concept in Bayesian networks.

Expected utility

When actions have uncertain outcomes, an agent can compare actions using expected utility:

\(EU(a)=\sum_s P(s\mid a)U(s)\)

Here, s represents possible outcomes and U(s) is the utility of an outcome.

Markov decision processes

An MDP contains states, actions, transition probabilities, rewards and a discount factor. The Markov property means the next state depends on the current state and action rather than the full history.

Worked example

Question: An action produces utility 10 with probability 0.6 and utility 0 with probability 0.4. Find expected utility.

EU = 0.6 × 10 + 0.4 × 0 = 6.

Practice questions

  1. What type of graph represents a Bayesian network?
  2. What does a conditional probability table describe?
  3. What is the Markov property?
  4. How is expected utility calculated?
Reveal answers

1. Directed acyclic graph. 2. A node's probability distribution given its parent variables. 3. The next state depends on the current state and action, not the entire history. 4. Sum of outcome probabilities multiplied by their utilities.
