01Engineering MathematicsFunctions · Calculus · Matrices＋

Functions and Limits

  • A function assigns exactly one output to each permitted input.
  • Domain: permitted input values; range: resulting output values.
  • A limit describes the value approached by a function near a point.
  • For polynomials, direct substitution evaluates the limit.

Differentiation – Important Rules

  • Power Rule: When differentiating a power of x, bring the exponent in front and reduce it by one.

    Example: If y = x³, its derivative is 3x².

    Rule: \(\frac{d}{dx}x^n=nx^{n-1}\)

  • Product Rule: Use this when two functions are multiplied. Differentiate the first function and multiply it by the second, then add the first function multiplied by the derivative of the second.

    Rule: \((uv)'=u'v+uv'\)

  • Quotient Rule: Use this when one function is divided by another. Multiply the denominator by the derivative of the numerator, subtract the numerator multiplied by the derivative of the denominator, and divide by the denominator squared.

    Rule: \((u/v)'=(vu'-uv')/v^2\)

  • What does a derivative mean? A derivative tells us how quickly something changes at a particular moment. On a graph, it represents the slope of the tangent at a point.

    Example: In motion, the derivative of position with respect to time gives instantaneous velocity.

Matrices

  • Matrix order is rows × columns.
  • Matrix addition requires equal dimensions.
  • For an invertible square matrix, determinant is non-zero.
  • Rank is the maximum number of linearly independent rows or columns.
Worked example

If \(f(x)=x^2+3x\), then \(f'(x)=2x+3\). At \(x=2\), the derivative is 7.

Easy · Question 1

What is the derivative of \(x^4\)?

Reveal answer

Answer: \(4x^3\). Apply the power rule.

Moderate · Question 2

What is the determinant of an identity matrix of order 3?

Reveal answer

Answer: 1. The determinant of every identity matrix is 1.

02Programming FundamentalsPython · Logic · OOP＋

Core Programming Concepts

  • A variable stores a reference to a value.
  • Common Python types include int, float, str, bool and list.
  • Conditional statements control execution based on Boolean expressions.
  • Loops repeat a block of instructions.
  • A function groups reusable instructions and may return a value.

Object-Oriented Programming

  • Class: a blueprint for creating objects.
  • Object: an instance of a class.
  • Encapsulation groups data and methods while controlling access.
  • Inheritance allows a class to reuse and extend another class.
  • Polymorphism allows a common interface to support different implementations.
Worked example

A loop running from 1 through 5 executes five iterations. A counter can track the number of iterations.

Easy · Question 1

Which Python keyword defines a function?

Reveal answer

Answer: def. It introduces a function definition.

Moderate · Question 2

Which OOP principle allows a child class to reuse parent-class features?

Reveal answer

Answer: Inheritance. A derived class can extend an existing class.

03Data Structures and AlgorithmsArrays · Searching · Stacks＋

Complexity and Searching

  • O(1): constant time.
  • O(log n): logarithmic growth.
  • O(n): linear growth.
  • O(n log n): common efficient sorting complexity.
  • O(n²): often appears in two nested loops.
  • Binary search requires sorted input and runs in O(log n) time.

Linear Data Structures

  • Array: indexed collection of elements.
  • Stack: follows LIFO (Last In, First Out).
  • Queue: follows FIFO (First In, First Out).
  • Linked list: nodes connected through references.
  • Push inserts into a stack; pop removes its top element.
Worked example

For a stack receiving A, B and C in that order, the first item removed is C because the stack follows LIFO.

Easy · Question 1

Which data structure follows FIFO?

Reveal answer

Answer: Queue. The earliest inserted element is removed first.

Moderate · Question 2

What is the worst-case time complexity of linear search?

Reveal answer

Answer: O(n). It may inspect every element.

04Database Management SystemsSQL · Keys · Normalisation＋

Database Fundamentals

  • A database organises information for storage and retrieval.
  • A primary key uniquely identifies each row.
  • A foreign key references a key in another table.
  • Candidate keys are minimal sets of attributes that uniquely identify rows.

SQL and Normalisation

  • SELECT retrieves data; INSERT adds rows; UPDATE modifies rows; DELETE removes rows.
  • WHERE filters rows; ORDER BY sorts results.
  • GROUP BY groups rows for aggregate calculations.
  • 1NF requires atomic values and no repeating groups.
  • Normalisation helps reduce redundancy and update anomalies.
Worked example

SELECT name FROM Students WHERE marks > 80; retrieves names of students whose marks exceed 80.

Easy · Question 1

Which SQL clause filters rows?

Reveal answer

Answer: WHERE. It applies a condition to selected rows.

Moderate · Question 2

Which key uniquely identifies a record in a table?

Reveal answer

Answer: Primary key. Its values must be unique and non-null.

05Operating SystemsProcesses · Memory · Scheduling＋

Processes and Threads

  • A process is a program in execution.
  • A thread is a unit of execution within a process.
  • Context switching changes the CPU from one execution context to another.
  • Scheduling decides which ready process receives CPU time.

Memory and Deadlocks

  • RAM provides working storage for active programs.
  • Virtual memory gives processes an abstraction of a larger address space.
  • Paging divides memory into fixed-size pages and frames.
  • Deadlock involves processes waiting indefinitely for resources.
  • The four necessary deadlock conditions are mutual exclusion, hold and wait, no preemption and circular wait.
Worked example

Round Robin scheduling gives each ready process a time slice before moving to the next process.

Easy · Question 1

What is a program in execution called?

Reveal answer

Answer: Process.

Moderate · Question 2

Which scheduling method uses a time quantum?

Reveal answer

Answer: Round Robin. Each process receives a fixed time slice.

06Computer NetworksOSI · TCP/IP · Protocols＋

Network Models

  • OSI has seven layers: Physical, Data Link, Network, Transport, Session, Presentation and Application.
  • TCP provides reliable, connection-oriented transport.
  • UDP provides connectionless transport with lower overhead.
  • IP handles logical addressing and packet routing.

Common Protocols

  • HTTP/HTTPS: web communication.
  • DNS: translates domain names into IP addresses.
  • DHCP: assigns network configuration automatically.
  • SMTP: sends email.
  • FTP: transfers files.
Worked example

When a user enters a domain name, DNS helps find its corresponding IP address before the device communicates with the destination.

Easy · Question 1

How many layers are in the OSI model?

Reveal answer

Answer: Seven.

Moderate · Question 2

Which protocol translates domain names into IP addresses?

Reveal answer

Answer: DNS. It provides domain-name resolution.
